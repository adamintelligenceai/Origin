# Evidence Room Brand Design System

## Brand Idea
**Evidence over hype.** Evidence Room turns Finance AI from experimentation into measurable operating performance.

## Positioning Statement
The operating system for building, governing, and scaling AI agents across Finance operations. AP Agent OS is the first vertical.

## Voice
- Intelligent, concise, credible, executive
- Specific, non-hype, confident without exaggeration
- Never promise guaranteed savings, fraud detection, compliance, or ROI

## Logo Direction
Wordmark: **Evidence Room** — serif "Evidence" + lighter weight "Room"
Accent mark: Small gold square (■) before the wordmark — represents evidence blocks
No robots, brains, circuits, or purple gradients

## Colour System
| Token | Hex | Usage |
|-------|-----|-------|
| Ink | #0B1220 | Primary text, nav, hero backgrounds |
| Slate | #1E293B | Secondary backgrounds |
| Stone | #64748B | Body text, captions |
| Paper | #F8FAFC | Page backgrounds |
| Accent | #0F4C5C | CTAs, headings, links |
| Accent Light | #1A6B7C | Hover states |
| Gold | #B8860B | Accent mark, premium highlights |
| Border | #E2E8F0 | Cards, tables, dividers |

## Typography
- **Headings:** Georgia / Times New Roman (serif) — institutional authority
- **Body:** Inter / Helvetica Neue (sans-serif) — modern clarity
- **Data/Code:** JetBrains Mono — KPI tables, agent codes

## Product Family Architecture
```
EVIDENCE ROOM (master brand)
└── AP Agent OS (vertical product)
    ├── Free Diagnostic
    ├── Starter Kit
    ├── Professional
    ├── Team Edition
    └── Custom Blueprint
```

Future: AR Agent OS, Close Agent OS, Treasury Agent OS, etc.

## Aesthetic References
Institutional investment research · Bloomberg terminal clarity · Stripe simplicity · Linear precision · McKinsey report structure · Premium financial software

## Chart Style
- Minimal gridlines, accent colour for primary data
- Stone grey for benchmarks/comparisons
- No 3D effects, no gradients on charts
- Source citations below every data visualisation

## Cover System
- Dark (ink) background with white serif title
- Gold accent line above title
- Product tier label in stone grey below title
- Version number bottom-right in mono font
