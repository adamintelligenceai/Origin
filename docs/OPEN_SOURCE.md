# Open-source disclosures

Dependency licence inventory is generated in CI via the licence audit workflow.

Planned runtime dependencies include:

- Next.js (MIT)
- React (MIT)
- DuckDB-Wasm (MIT)
- Papa Parse (MIT)
- SheetJS Community Edition (Apache-2.0 — attribution required)
- Zod (MIT)
- Vitest (MIT)

Run `pnpm licences list` after install to inspect the full tree.
