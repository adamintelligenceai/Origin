# Founder Tool Kit

## You already have

- Cursor — implementation cockpit
- ChatGPT — architecture/integration/product reasoning
- Claude — adversarial code/security review
- Gemini — Google/Android ecosystem review
- Grok — product/market critique

Subscriptions are for building/reviewing. Production users must run through commercial APIs/terms appropriate to the product.

## Add when needed

- GitHub — repository, CI, releases
- Google Cloud Console — OAuth/API project
- OpenAI API — first runtime model provider
- Anthropic API — optional second provider after abstraction works
- Stripe — paid alpha
- Supabase/Postgres — content-blind control plane only
- Vercel — marketing/control plane
- Apple Developer Program — when iOS distribution starts
- Google Play Console — when Android distribution starts

## Do not add initially

- Composio/Zapier-style connector layer
- Browserbase/cloud browser
- Pinecone/vector cloud
- Datadog containing app payloads
- central email/document warehouse
- complex Kubernetes/microservices
