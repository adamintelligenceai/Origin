# Launch Runbook

## Stage 0 — synthetic build
Goal: complete core loop with fake data.

Exit:
- UI usable;
- permission engine green;
- local encryption green;
- receipt flow green.

Spend: effectively zero beyond existing tools/API testing.

## Stage 1 — founder dogfood
Use only founder-controlled accounts.

Daily:
- read morning briefing;
- approve/reject every suggested action consciously;
- record false positives;
- record what had to be done manually;
- record minutes saved;
- record any surprise/privacy discomfort.

Weekly metrics:
- proactive insights
- accepted decisions
- dismissed decisions
- verified actions
- failed actions
- undo count
- estimated minutes saved
- prompts initiated by user vs Chief-initiated work

Exit:
"I would be meaningfully annoyed if this disappeared."

## Stage 2 — 5 trusted testers
Manual onboarding.
No advertising.

Interview after:
- day 1
- day 7
- day 21

Question:
"What did Chief do that you would otherwise have had to remember or do yourself?"

Exit:
- at least 3/5 actively use it after 3 weeks;
- low false-positive fatigue;
- no serious action failures.

## Stage 3 — 10–25 founding customers
Charge early.
One plan.
Manual onboarding.
Founder support.

Do not scale acquisition yet.

Exit:
- customers renew;
- direct costs controlled;
- reliable activation.

## Stage 4 — first 100
Founding price.
Referral loop.
Content demos.
Communities of executives/founders/consultants.
No mass consumer ads.

Invest early revenue in:
1. external security review
2. OAuth/public verification work
3. legal/privacy review
4. only then paid growth experiments

## Stage 5 — scale
Add Microsoft when Google wedge retains.
Household only after professional use is robust.
Always-on confidential cloud only when users prove willingness to pay for it.
