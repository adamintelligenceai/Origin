# Support process

Founding support is founder-operated. Do not collect mailbox content.

## What users can send

- Diagnostic bundle from Privacy → Export diagnostics (counts, connection status, flag state).
- App version and OS.
- Whether mutations were paused (kill switch / offline).
- Connector names that failed, never raw tokens.

## What support must refuse

- Paste of email bodies, calendar titles, SMS, or model prompts.
- Refresh or access tokens.
- A request to recover a wiped device from the service cloud. There is no escrow.

## Pairing recovery

1. Revoke the companion connection on desktop.
2. Generate a new local pairing code with Pair.
3. Confirm the code on the handset. Call audio never leaves the phone.

## Incidents

Follow `docs/INCIDENT_RUNBOOK.md`. Prefer local diagnostic bundles that have already been scrubbed.
