# Bootstrap Economics

## Objective
Reach revenue before meaningful fixed spend.

### Founder-funded cap
Target cumulative pre-revenue cash: **A$500–2,500**, excluding hardware already owned.

### Fixed cost philosophy
- free tiers while non-commercial;
- pay-as-you-go model APIs;
- direct Google APIs;
- no connector aggregator initially;
- no cloud browser initially;
- no employee/agency initially.

### Revenue guardrails
Target mature blended ARPU: ~A$100–120/month.

Target direct costs:
- AI + provider/API: < A$10–15/user/month
- payment/platform: < A$5–8
- other infra allocation: < A$3–5
- total direct COGS target: < 20% revenue, aspirational 15%

### Spend unlocks
- A$0 MRR: founder only
- A$1k MRR: pay for required tooling/API
- A$5k MRR: create legal/security reserve
- A$10k MRR: targeted professional review
- A$25k MRR: deeper pentest/compliance/growth experiments

Do not hire just because the roadmap is long. Hire only when a bottleneck is proven and revenue/traction supports it.
