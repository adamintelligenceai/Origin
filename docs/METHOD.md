# MarginShield Methodology

This document describes the MarginShield Leakage Ledger methodology.

See `BLUEPRINT.md` for the authoritative specification. Key concepts:

- **Value classes**: Detected leakage, policy leakage, modelled margin opportunity, cash entitlement, etc.
- **Evidence grades**: A (documentary), B (calculated), C (modelled)
- **Single-count tranche allocation**: Sell-side overlapping gaps counted once via running maximum
- **Bankability planning**: Scenario-based planning ranges, not statistical probabilities

Implementation details are added as each phase completes.
