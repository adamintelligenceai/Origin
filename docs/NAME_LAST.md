# Name & Domain — Deliberately Last

The user explicitly chose to decide the website/product name **after** architecture, product and experience are locked.

Until then:

- internal repo name: `project-chief`
- UI constant: `PRODUCT_NAME`
- no logo
- no trademark application
- no premium domain purchase
- no public social handles

Final naming process:

1. define brand attributes from finished product;
2. generate 50 candidates;
3. eliminate pronunciation/spelling/confusion problems;
4. current web/company collision search;
5. trademark screening in intended launch markets;
6. domain availability/current price;
7. app-store name collision;
8. social handle check;
9. linguistic check in major markets;
10. choose once and replace `PRODUCT_NAME`.

Do not buy an expensive premium `.com` before paid validation.
