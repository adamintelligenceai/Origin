# Team maturity assessment

**Product:** Evidence Room — AP Agent OS · Team  
**Use:** Score the 36-question diagnostic *as a working group* so the band is shared.  
**Rules:** Same 0–4 rubric, same vetoes as `01_FREE_AP_AI_READINESS/DIAGNOSTIC_GUIDE.md`. This file is the sitting procedure, not a second model.

---

## 1. Roles in the room

| Role | Who | Duty |
|---|---|---|
| Scorer | Transformation | Writes the number |
| Challenger | Controls | Demands the artefact |
| Owner voice | Process Owner | Breaks ties downward |
| Recorder | Any | Artefact names |
| Observer | Audit optional | Does not vote |

Ties: **lower score wins.**

---

## 2. Sitting procedure (90 minutes or workshop Exercise 1)

1. Read the veto list first (C1, C2, A5, E1, E2, F6).
2. Score Controls dimension first if time is short — a technology-first sit hides payment gaps.
3. For each question: artefact or 0–1.
4. Do not use Northline scores.
5. Compute six averages. Do not compute a seventh “overall % ready.”
6. Apply caps. Write the L1–L5 sentence from `MATURITY_MODEL.md`.
7. Sign the band page (Process Owner, Controls, Transformation).
