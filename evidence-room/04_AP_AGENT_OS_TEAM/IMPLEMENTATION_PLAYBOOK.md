# Implementation playbook — Team

**Product:** Evidence Room — AP Agent OS · Team  
**Audience:** Working-group lead (usually Transformation + AP Process Owner)  
**Use:** Coordinate several functions without turning the layer into a programme factory.

This playbook assumes Professional content is available to the group. Individual Starter users should not run a Team playbook on an Individual licence.

## 4. Workstreams (only four)

1. **Holds** — payment, bank, DOA, close.
2. **Path** — map, codes, five invoices.
3. **Charters** — six JDs.
4. **Instrument** — objects, access, ledger.

A fifth workstream called “value” or “ROI” is refused. Observed benefits go to `BENEFITS_REALISATION_TRACKER.md` after they exist.
