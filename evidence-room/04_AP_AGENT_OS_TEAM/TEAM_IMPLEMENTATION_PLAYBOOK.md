## 1. What Team delivers

Team scales the AP Agent OS from one supervised agent to a **people-and-agents programme**: facilitation artefacts, training paths, executive narrative, implementation tracking, and change communications.

| Module | Path | Outcome |
|---|---|---|
| Workshop | `Workshop/` | Facilitated design sessions with decks, interviews, exercises |
| Training | `Training/` | Role-based materials + maturity reassessment |
| Executive | `Executive/` | CFO / steering / business-case outlines |
| Implementation | `Implementation/` | Tracker, benefits realisation, roadmap |
| Change | `Change_Management/` | Toolkit + executive comms templates |

**Prerequisites:** Starter logic understood; ideally Pro artefacts in progress or complete. Readiness diagnostic completed.

## 5. Non-negotiables

1. No guaranteed savings / fraud / compliance / ROI claims in internal or external decks.  
2. Payment execution remains out of default agent scope.  
3. Scope and autonomy never expand in the same change window.  
4. Every agent answers the seven product questions.  
5. Numeric industry claims only from ledgered sources (Ardent 2025 figures above).

## 6. Success definition (Team)

Programme success is **governed capacity**, not vanity automation:

- Documented multi-agent portfolio with owners  
- Live KPI scorecards for wave-1 agents  
- Trained cohorts on analyst / approver / audit paths  
- Steering cadence running  
- Change narrative issued without hype  
- Clear upgrade or Custom Blueprint decision at week 12
