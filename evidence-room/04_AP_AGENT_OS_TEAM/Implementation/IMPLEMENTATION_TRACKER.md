# Implementation tracker

**Evidence Room · Team**  
**Version:** 1.0 · September 2026  
**Use:** Named tasks from “one mapped class” to “one governed agent in a limited fence”  
**Not:** a vendor implementation plan, an ERP cutover, or a 16-agent programme

Entry criteria: workshop artefacts exist (map, sentence, fence) **or** a written Diagnostic “wait” that this tracker is only mapping.

Exit criteria: written hold / limited continue / stop, register row, three measures sourced, pause rehearsed.

Northline is fictional. Payment stays human. No savings column.

---

## How to use

1. Copy this file (or rebuild as a sheet). Keep IDs stable.
2. One owner per row. “Team” is invalid.
3. Status: `NS` not started · `IP` in progress · `BLK` blocked · `DN` done · `CAN` cancelled (reason required).
4. Do not add a “savings realised” field.
5. Review in steering using tracker IDs, not slide titles.
