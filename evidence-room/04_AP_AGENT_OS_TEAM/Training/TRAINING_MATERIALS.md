## 2. Module outlines

### M0 — Programme overview
- Evidence over hype; stack honesty  
- Five planes; responsibility stages S0–S5  
- Industry climate cited once: Ardent 2025 cost **$9.84** / BIC **$2.65** / exception **18.4%** / STP **35.4%** / AI adoption **44%**  
- What we never claim  

### M1 — Analyst: agent supervision
- Reading JD and instructions  
- Run logs and evidence refs  
- Taxonomy coding lab  
- When to override and how to reason-code  

### M2 — Analyst: failure modes
- Hallucinated fields  
- Forced matches  
- Inquiry answers without SoR cites  
- Stop-condition drills  

### M3 — Approver path
- Packet completeness checklist  
- SoD reminders  
- Challenging “green” agent summaries  
- Escalation etiquette  

### M4 — Audit path
- Sampling AI-assisted decisions  
- Retention and retrieval tests  
- Change control of instructions  
- Promotion gate audits  

### M5 — Manager refresh
- Weekly/monthly forums  
- Reading the KPI scorecard without vanity  
- Demotion scenarios

## 3. Learning checks (pass = 80%)

**Sample items**

1. Name the seven product questions.  
2. List three prohibited agent actions in default Starter/Team posture.  
3. Map a duplicate suspicion to an exception code and owner.  
4. Explain why industry STP **35.4%** must not be pasted as a customer target without baseline.  
5. Describe a valid demotion trigger.
