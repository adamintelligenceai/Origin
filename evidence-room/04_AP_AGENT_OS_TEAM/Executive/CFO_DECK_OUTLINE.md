# CFO Deck Outline — AP Agent Investment / Update

**Use:** Board lite, ExCo, or CFO 1:1  
**Tone:** Institutional, evidence-led, no hype  
**Length:** 8–12 slides

---

## Slide-by-slide

### 1. Title
Evidence Room AP Agent Programme — [Company]  
Subtitle: Governed agents. Measurable outcomes.  
Date / confidential marking

### 2. The operating problem (not “AI opportunity”)
3 bullets: cost-to-process pressure · exception backlog · control evidence burden  
Optional: one volume chart (internal data only)

### 3. What we are building
Agent layer across ERP — not an ERP replacement  
Diagram: Intake → Match → Exception → Pay-prep (human auth) → Close

### 4. Principles (non-negotiables)
Agents earn responsibility · Payment auth human · Evidence on material actions · Metrics separated by class

### 5. Current state scorecard
Four quadrants: Activity / Operational / Financial / Risk  
Traffic lights with definitions

### 6. What we ran (shadow / pilot evidence)
Sample sizes, precision/recall on critical classes, defects closed  
Show one failure and fix (trust)

### 7. Economics (assumption-labelled)
Cost stack · benefit hypotheses · realisation % · sensitivity  
Explicit: not a guaranteed ROI

### 8. Risk & control
Top 5 risks · residual · kill switch · SoD  
Internal Audit stance if available

### 9. Ask
Investment $X · scope · level · timeline · kill criteria

### 10. 90-day plan
Milestones only

### 11. Appendix
Charter summary · RACI · taxonomy · glossary

## Speaker notes cues
