# Training materials

**Product:** Evidence Room — AP Agent OS · Team  
**Use:** Role-based outlines you can teach in short sessions.  
**Not:** A certification programme. Completing training does not make an agent safe or an organisation compliant.

Deliver internally. Do not upload production invoices into a public model to “demo.”

---

## 1. Core module (all roles) — 40 minutes

| Min | Content |
|---|---|
| 5 | Lockup, brand idea, keep the stack |
| 10 | Sixteen names; Wave 1 six |
| 10 | L0–L4; default L0/L1; payment ceiling |
| 10 | Packet minimum; flag ≠ fraud |
| 5 | STOP words; who to call |

**Check question:** “Can Agent 12 release under $5k if match is clean?” Correct answer: No.

---

## 2. Operator module — 45 minutes

- Shadow vs recommend.
- Accept / edit / reject.
- Incomplete packet stops.
- Dummy GR forbidden.
- How to reject without drama.
- Practice: three tickets with bait language.

**Exercise:** Rewrite “AI caught fraud, release the rest” into a lawful ticket.

---

## 3. Matcher module — 45 minutes

- Worksheet fields.
- Tolerance read-only.
- Open flag blocks match-recommend.
- Sample disagreement log.
- Charter caps (value, first invoice, entity).

---

## 4. Controls module — 45 minutes

- Four outcomes.
- Register hygiene.
- Language sample method.
- High-value clearance.
- Demotion right.

---

## 5. Payments / Treasury module — 30 minutes

- Three jobs: build (ERP), annotate (agent ≤ L2), authorise (humans).
- Discount is not a release criterion.
- How to read annotations.
- Incident if a file left without humans.

---

## 6. Owner / Process Owner module — 45 minutes

- Charter maintenance.
- Vacant owner = pause.
- Orchestrator fields.
- Cost ledger.
- Steering papers.
