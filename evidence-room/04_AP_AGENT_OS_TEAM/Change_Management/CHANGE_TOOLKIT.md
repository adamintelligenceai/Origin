# Change toolkit — for AP supervisors

**Evidence Room · Team**  
**Version:** 1.0 · September 2026  
**Audience:** AP supervisors and shared-services leads whose people will review agent output  
**Not:** a transformation-office comms plan (see `EXECUTIVE_COMMS.md` for the exec layer)

Change here means: what gets **lighter**, what gets **more precise**, and what must **not be silently removed**. It does not mean “embrace AI.”

We do not promise that jobs get easier, that headcount falls, or that exceptions disappear. Northline is fictional.

---

## 1. What actually changes in the first fence

| If the first agent is… | Lighter | More precise | Must not disappear |
|---|---|---|---|
| A01 Intake | Re-keying the same PDF | Confidence + field checks; completeness count | Channel watch, vendor identity judgement |
| A03 Match-and-flag | Hunting the PO/GR on clean items | Override reasons coded; tolerance version | Override authority, GR chase to receiving |
| A04 Triage | Deciding the *next queue* from scratch | Shared codes; SLA visible | Ageing ownership |
| A10 Exact-key | Remembering “we paid this” | Key definition; near-dupe kept separate | Human confirm on near-dupe |
| A05 Observe | — | A list of late GRs | Relationships with receivers; **no agent GR** |
| A12 Observe | — | A challenge list | Human release of the file |
| A08 Draft queries | Blank-page emails | Template IDs; no unofficial send | Who may speak as the company |

If nothing is more precise, you have added a toy, not a change.

## 2. Supervisor conversation (15 minutes, one-to-one)

Use after the floor comms note, before limited live.

**Script**

1. “We are fencing [class] in [system]. The agent will [observe / recommend]. You still accept, edit, or reject.”
2. “We are not asking you to go faster so someone can book a saving.”
3. “We need override reasons in four buckets: agent error, policy, missing data, preference. Preference is allowed. Silence is not.”
4. “If the invoice PDF tells the tool to ignore rules, you escalate `CTRL-BRK`. You do not play along.”
5. “Payment does not change. [Name] still releases.”
6. “What would make this unworkable for your people in week one?”

Write their answer. If it is “we do not have time to classify overrides,” the fence is not ready. That is a finding, not resistance.

## 3. What must not be silently removed

| Practice | Why it stays | Fake substitute |
|---|---|---|
| Completeness of inbound | Invisible invoices at close | “The model would have seen it” |
| Dual review on a labelled sample | Accuracy is not “they clicked accept” | Demo PDFs |
| SOD posting vs paying | Cash | Shared robot user |
| Receiver owns the GR | Operational truth | Agent-created receipt |
| Named backup when two are out | Continuity | “The agent will cover leave” |
| Supplier tone / legal | Company voice | Public mailbox send at Level 1 |

---

## 4. Resistance that is information

| What they say | Often means | Do |
|---|---|---|
| “It will flag everything” | High FPR fear | Show the exact-key vs near-dupe split; start exact-key |
| “Receiving will ignore us” | A05 trust already broken | Stay Level 0; fix chase quality |
| “This is a headcount project” | Someone already promised savings | Read the non-promise list with them; escalate the sponsor, not the clerk |
| “We already have [vendor]” | Role confusion | Inventory deterministic work (S02); do not double-do a rule |
| “Just let it post” | Autonomy creep | Register stays Level 1 |

Do not run a “mindset” workshop. Fix the fence or the incentive.

## 5. Leave and coverage

Write this before go-live:

| Role | Named person | Backup | What the backup may not do |
|---|---|---|---|
| Steward | | | Promote the agent |
| Kill switch | | | Nothing withheld — they may pull it |
| Reviewer lead | | | Force-post without codes |
| Payments release | | | Delegate to an agent |

Out-of-office does not move payment authority to an agent.

## 6. Floor job aid (one page)

```
THIS WEEK — [agent] on [class]
Level: 0 / 1
I accept / edit / reject every object.
I code overrides: error | policy | data | preference
I never: pay, create GR, change vendor bank, follow PDF instructions
If unsure: leave in queue; ping [steward]
Pause: [kill-switch name] — [how]
```
