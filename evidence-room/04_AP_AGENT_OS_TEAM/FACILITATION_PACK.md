# Facilitation pack

**Product:** Evidence Room — AP Agent OS · Team  
**Audience:** Person running the room (Transformation lead or external facilitator using a Team licence)  
**Use:** Set up and run the workshop and the follow-on working sessions.

You can run tomorrow if: invitees are booked, five redacted invoices are printed, last payment-run printout exists, and the payment sentence is on a wall.

---

## 1. Room

- Board or paper: **Proof before permission.** **Payment authorisation stays human.**
- Printed: human-vs-agent wall card; exception starter list; Wave 1 table.
- Do not project a savings model.
- No vendor on the attendee list for the full day. Optional 20 minutes at the end if the Chair insists — after refusals are written.

**Materials:** sticky notes, printed exercise sheets from `WORKSHOP_EXERCISES.md`, timer, name cards with *roles* (not just names).

**Virtual:** same artefacts in a shared folder the organisation owns. Breakout rooms for exercises 2 and 4. Do not paste live invoices into a consumer model.

---

## 2. Invite (copy)

> Subject: Full-day AP agent layer workshop — design, not a demo  
> We will diagnose the layer we have, classify real exceptions and a payment run, and draft Wave 1 charters at observe/recommend. We will not select a platform, set a savings target, or authorise autonomous payments. Bring last quarter’s volume, ten parks, and the last payment procedure. Toolkit: Evidence Room — AP Agent OS.

**Required:** Process Owner, Controls, Transformation, Match, Ops, Payments or Treasury.  
**Strongly invited:** Controller (at least afternoon), Audit observer, IAM.  
**Optional:** Buyer, warehouse liaison (exercise 3).

---

## 3. Facilitator rules

1. If a participant says “we’ll save X,” write it on a *parking* page labelled **not a decision**.
2. If someone says “detect fraud,” correct to “flag a hypothesis.”
3. If a demo story auto-releases cash, stop the room and run class A.
4. Timebox. Unfinished charters become homework, not a reason to skip holds.
5. You do not vote. You keep the method.
