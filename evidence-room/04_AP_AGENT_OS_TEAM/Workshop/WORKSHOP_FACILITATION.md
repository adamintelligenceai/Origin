# Workshop facilitation — 1-day and 2-day

**Evidence Room · Team**  
**Version:** 1.0 · September 2026  
**You run this.** Evidence Room does not attend.  
**Materials:** `EXERCISES.md` · `INTERVIEW_GUIDE.md` · `PROCESS_OWNER_QUESTIONNAIRE.md` · Professional library  
**Voice in the room:** nouns from the operation. No “unlock.” No demo until asked.

Read the non-promise script from the Team Playbook at 09:00 and again before the executive hour.

---

## Preconditions (or convert the day)

Do not start agent selection if any of these are false:

| Precondition | If false |
|---|---|
| Diagnostic completed by at least the process owner and one floor person | First 45 minutes become Diagnostic, not ice-breakers |
| Process-owner questionnaire returned | Use interview guide live; cut Exercise 3 |
| A room with a wall / whiteboard | Delay. Slides-only workshops produce policy maps |
| Control owner available for the control block | You may design a fence; you may not call it governed |
| Payment-release (C01) is written or will be written today | A12 is Observe-only discussion; no “payment agent” language |

## Roles on the day

| Role | Duty |
|---|---|
| Facilitator | Timing, cuts vendor stories, holds the fence |
| Scribe | Writes artefacts into the templates *as the room speaks* |

## Facilitation notes (the failures)

| Failure | What you do |
|---|---|
| Someone maps the SOP | Hand the pen to the floor witness. Ask “what happens when the GR is late?” |
| “Let’s include NetSuite too” | Write it on the **out** list. One book this workshop. |
| “The agent should just pay matches” | Read A12 exclusion. Rewrite the sentence. |
| Control owner is silent | Ask them to name a veto they would use tomorrow. If they cannot, you do not have a control owner. |
| Time evaporates on capture vendors | Park in a “tools already deterministic” list (S02). Agents do not replace a working rule. |
| Energy for ten agents | Write “wave 0–1 only” on the wall. A16 + one processor. |
| Savings slide appears | Remove it. Offer the business-case starter: customer baseline or nothing. |
| Northline copied as if real | Strike their numbers. Write yours. |

Scribe circulates: map photo or typed table, purpose sentence, fence, JD draft, control/measure card, sample plan, action list. Process owner files them in the same place as SOPs. Control owner confirms receipt.
