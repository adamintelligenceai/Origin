## Exercise 1 — Diagnostic compare (45–60 min)

**Setup.** Each seat brings their completed scorecard. Do not average in silence.

**Steps**

1. Write declared levels on the wall. Do not debate yet.
2. For each domain, show the spread (lowest / highest).
3. Log disagreements that change a hard gate (C01, P01+P05, E05+E06).
4. Apply hard gates as a room. The lowest honest gate wins.
5. Declare **one** level for the workshop slice.

**Artefact**

| Seat | Level they brought | Weakest two domains |
|---|---|---|
| | | |
| **Room declared level** | | |
| **Wait?** | Yes / No | |

**Facilitator prompt.** “If we are Level 1, we fence a trial. We do not design ten agents.”

## Exercise 2 — Live-process map (90–120 min)

**Setup.** Wall. Steps pre-written: Receipt, Capture, Code, Match, Exception, Approve, Schedule, Pay, Archive.

**Steps**

1. Floor witness narrates Tuesday. Others may only ask “then what?”
2. Policy owner may speak only to be **struck**.
3. Mark systems, queues, waits.
4. Walk the last annoying invoice from interviews along the wall.
5. Ask the floor: “Is this Tuesday?” If no, keep going.

**Ex 2b (2-day):** list inbound channels and whether yesterday’s count is reconcilable.

**Ex 2c (2-day):** map local reasons → library codes / E-codes. Do not invent synonyms.

**Artefact.** Photo + typed table (Starter §6 or Professional templates).

**Northline illustration (fictional).** Shared inbox after match; GR wait at Plant 1200; NetSuite not on this wall.

## Exercise 4 — Purpose sentence (30–40 min)

**Pattern.** Flag [condition] on [class] for human release. Do not [pay / override / new vendor / close].

**Rounds**

1. Silent write, 4 minutes.
2. Read aloud. Tear any sentence with “autonomously,” “ensure compliance,” or a savings clause.
3. Vote only to **narrow**, not to add scope.
4. Executive dry-run: one person reads it as if to a CFO. If they smirk, rewrite.

**Artefact.** One sentence, owner, date.
