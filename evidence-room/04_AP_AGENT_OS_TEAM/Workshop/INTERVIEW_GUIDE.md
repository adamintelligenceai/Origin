# Interview guide — before the workshop

**Evidence Room · Team**  
**Version:** 1.0 · September 2026  
**Use:** 25–40 minute conversations, three working days before the workshop  
**Not:** a survey, a vendor discovery call, or a chance to promise results

Interview **people who touch the work**. The process-owner questionnaire is a different file. Do not interview only managers and then call the map “live.”

Northline Industrial Group is fictional. Do not ask interviewees to comment on Northline as if it were a peer.

---

## Who to interview (minimum)

| Person | Why | Skip if |
|---|---|---|
| Matching or exception specialist | Tuesday truth | You only have a manager |
| Intake / capture clerk | Channel truth | All invoices are already structured e-invoice *and* they still work exceptions |
| Approver who is often late | DOA and reminder politics | Non-PO is out of the first fence |
| Receiver or warehouse clerk | GR-MISS reality | First class is non-PO services with no GR |
| Payments officer | C01, proposal noise | They will not discuss release — still interview; that *is* a finding |
| One supplier-facing communicator | Inquiry load | A08 is out of year-one scope |

Optional: Internal Audit (evidence), systems analyst (adapter), a buyer (PO quality). Do not interview a vendor’s customer-success manager as a substitute for the floor.

---

## How to run it

1. Explain: we are mapping the live path for a possible **governed** agent layer. We are not recording them for a demo. We will not ask for invoice images or vendor bank details.
2. Read: we do not promise savings, fraud detection, or that an agent will take their job. We want to know where work waits and what must stay human.
3. Take notes in the table below. Quote waits in their words.
4. End with: “What should we not automate even if it looks easy?”
5. Do not sell Starter, Professional, or Team in the interview.

If they ask “will this replace me?” answer: “This toolkit designs jobs and fences. Headcount decisions stay with your management. We will not put a savings number on this conversation.”

## Role add-ons

### Exception / matching specialist

| Ask | Note |
|---|---|
| Name your top five reasons — in your words, then we will code them later | |
| How often is “missing GR” actually a split receipt? | |
| When you override a match, who sees that? | |
| Do you have a second book (another ledger) that surprises you? | |

### Intake

| Ask | Note |
|---|---|
| List live channels you personally watch | |
| What arrives that is not an invoice? | |
| When is a vendor “unknown”? | |
| Completeness: do you know yesterday’s inbound count? | |

### Approver

| Ask | Note |
|---|---|
| Do you approve in the tool that policy named? | |
| What do you need in a packet that you do not get? | |
| Delegates: who actually clicks when you travel? | |

### Receiver

| Ask | Note |
|---|---|
| How do you hear about a missing GR today? | |
| What chase would make you ignore AP? | |
| Can anyone but you post the receipt? | |

### Payments

| Ask | Note |
|---|---|
| Who releases the file / batch / positive-pay? Name them | |
| What challenges do you already raise on a proposal? | |
| Has anyone offered a tool that would send the file? | |

### Supplier communications

| Ask | Note |
|---|---|
| Roughly what share of the week is inquiry handling? (A guess is fine; label it a guess) | |
| Which inquiries are “where is my invoice / payment”? | |
| Who is allowed to send as the company? | |

Ardent Partners (2024) notes that “All Other” AP departments spend 26.9% of time on supplier inquiries (independent context). Do **not** tell the interviewee they should hit a number. If they volunteer a share, write it as *their* estimate.
