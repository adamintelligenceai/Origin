# Workshop exercises

**Product:** Evidence Room — AP Agent OS · Team  
**Use:** With `WORKSHOP_AGENDA.md`. Print or share these sheets.  
**Facilitator key:** Northline answers are fictional illustrations, not a scoring key for the client.

---

## Exercise 1 — Diagnostic lightning (60 min)

**Setup.** Six posters (Process, Data, Controls, Technology, Talent, Economics). Questions A1–F6 from the free diagnostic on cards.

**Play.** Room scores 0–4. Controls may veto a score by saying “artefact.” If none, score falls to 0–1.

**Plenary (10 min).** Compute averages. Apply veto caps. Write the band sentence.

**Northline key (fictional):** C6=0 informal copilots; C1=4; band L2 Informal activity.

**Fail the exercise if:** the room averages C1 with D2 to “smooth” a payment gap.

---

## Exercise 2 — Ten + one (85 min)

**Sheet columns:** object · class A–J · modifiers · who decided · L1 ceiling · demo temptation · our refusal.

**Group A:** ten parks (bring your own; if missing, use the anonymised Northline ten below).  
**Group B:** last payment proposal (or Northline Tuesday run illustration).

**Northline ten (fictional, anonymised):**

| # | Situation | Class |

| 2 | Same + possible duplicate flag | H blocks C |
| 3 | Missing GR $18,500 Birmingham | C + E |
| 4 | Service $8,400, approver on leave | E / G |
| 5 | Supplier price $12.10 vs $11.40 | F / G |
| 6 | PO exhausted | G |
| 7 | Tax field missing on CA invoice | G (Tax) |
| 8 | Wrong entity | C — do not switch entity |

**Northline run (fictional):** 612 lines, $4.1m, two flags, one bank change yesterday → annotate holds; humans release.

**Debrief.** Each group reads one class A and one class H. Write the refusal minute.

## Exercise 3 — Six charters (90 min)

**Stations.** 01, 02, 03, 04, 10, 16. JD template. 12 minutes per station if rotating; or 40 minutes × 2 rounds of three.

**Required spoken line at each station:** exclusions.

**Vacant owner:** write VACANT; do not assign “the SSC.”

**Northline key:** Agent 10 L0 Elena Ruiz; Agent 03 L1 Jordan Hale; Agent 16 Marcus Chen.
