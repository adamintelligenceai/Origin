## 12-week Team programme (default)

| Week | Focus | Facilitator artefacts |
|------|-------|----------------------|
| 1 | Sponsor align + diagnostic refresh | Kickoff agenda (Pro Meeting Guide) |
| 2 | Process workshop (map + friction) | Workshop pack |
| 3 | Agent selection + charters | Agent Library + Charter template |
| 4 | Controls, risk, RACI | Governance + Controls |
| 5–6 | Shadow build & score | Testing guide |
| 7 | Pilot UAT + SOP/training | UAT + Training outline |
| 8–9 | Pilot run | Tracker + daily/weekly cadence |
| 10 | Stabilise + RCA #1 | Root Cause agent patterns |
| 11 | Benefits checkpoint | Benefits realisation |
| 12 | Steering decision (expand / hold) | Steering + CFO outline |

Compress only if shadow evidence already exists.

## How to run week 1

1. Confirm success metrics (≤3) and hard non-goals (no autonomous payments).  
2. Refresh readiness diagnostic.  
3. Book workshop attendees (processors must be present for observation playback).  
4. Stand up tracker + evidence folder structure.  
5. Identify kill-switch owner.

---

## Definition of done (Team engagement)

- [ ] Workshop outputs filed (map, friction top 10, agent shortlist)  
- [ ] Charters signed for pilot agents  
- [ ] Shadow + pilot evidence retained  
- [ ] Training completion logged for impacted roles  
- [ ] Steering pack delivered once  
- [ ] Benefits baseline and first checkpoint recorded
