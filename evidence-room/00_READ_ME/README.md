## Critical principles

1. Agents **earn** responsibility. Autonomy is never the default.
2. Payment authorisation remains **human-controlled**.
3. Every artifact answers: What / How / Who / Risk / Control / Measure / Evidence.
4. Claims about markets and benchmarks live in `09_RESEARCH/` with source attribution.
5. Licence and disclaimers: `10_LEGAL_AND_LICENSING/`.
