## What this product is

Evidence Room AP Agent OS is a commercial documentation and operating-model suite for finance teams that already own an AP stack and need a governed way to introduce AI agents.

It is **not** invoice-capture software, a payment network, or an ERP. Tipalti, Coupa, Basware, Stampli, Medius, HighRadius, Esker, AvidXchange, BILL, Ramp, SAP, Oracle, Microsoft, and similar platforms remain the systems of process and payment. Evidence Room designs the **agent layer** across them: scope, evidence, exceptions, KPIs, and responsibility progression.

### Why it exists (cited context)

Industry benchmarks show material headroom — and rising AI intent — without an operating model for agent authority:

- Ardent Partners *State of ePayables 2025* (Bottomline): average cost per invoice **$9.84**, cycle **8.2 days**, exception rate **18.4%**, STP **35.4%**. Best-in-Class cost **$2.65**, exception **11.1%**, STP **51.0%** (BIC costs **79% lower**, cycles **79% faster** vs peers). AI adoption **44%** now; **>75%** expected within 12 months; **65%** hope AI increases automation.
- Ardent Partners *State of ePayables 2024* (Medius distribution): average cost **$9.40**, cycle **9.15 days**, exception **14.0%**, STP **32.6%**; automation can cost **50–80% less** than manual.

Evidence Room does not claim these as customer results. They define the operating gap the suite addresses.

## START HERE — by buyer tier

### Exploring / assessing (no purchase)

1. Read this README.  
2. Complete `QUICK_START.md` steps 1–3.  
3. Open `01_FREE_AP_AI_READINESS/` and run the readiness assessment.  
4. Skim `09_RESEARCH/CUSTOMER_PROBLEM_DEFINITION.md` to confirm fit.

### Buying Starter ($297)

1. Confirm one AP use case (e.g. PO-invoice match exceptions, supplier inquiry triage).  
2. Purchase AP Agent Starter; open `02_AP_AGENT_STARTER/`.  
3. Complete the seven product questions for that agent (see Master Prompt §5).  
4. Instrument the Starter KPI sheet before expanding scope.

### Buying Pro ($997)

1. Ensure Starter logic is understood (or buy Pro if you already run pilots).  
2. Work `03_AP_AGENT_OS_PRO/` in order: Process Mapping → Agent Library → Controls → Governance → KPI Measurement → Testing → Business Case → Templates.  
3. Map agents to your existing AP/ERP tools — do not plan a rip-and-replace.

### Buying Team ($2,997)

1. Complete or parallel-track Pro artefacts.  
2. Use `04_AP_AGENT_OS_TEAM/` for workshop facilitation, training paths, change management, executive narrative, and multi-agent implementation.  
3. Align Internal Audit early — governance packs are written for that conversation.

### Buying Custom Blueprint (from $15,000)

1. Contact via the Custom Blueprint intake in `05_CUSTOM_BLUEPRINT/`.  
2. Expect current-state mapping, agent workforce design, governance charter, and a 90-day responsibility roadmap.  
3. Bring AP system owners and audit stakeholders to kickoff.

## Product principle (reminder)

Every agent must answer:

1. Permitted work  
2. Required evidence  
3. Exception ownership and taxonomy  
4. KPIs for earned responsibility  
5. Promotion / demotion rules  
6. Failure and ambiguity handling  
7. Audit trail
