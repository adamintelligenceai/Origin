# Quick Start — Evidence Room AP Agent OS

**Time to first useful output:** 90–180 minutes  
**Owner:** Finance Transformation lead or Head of AP

---

## Monday morning path

### Hour 1 — Orient and baseline

1. Skim `PROFESSIONAL_OS_GUIDE.md` (or Starter Kit if that is your tier).
2. Complete the **AP AI Readiness Diagnostic** (35 questions) in `01_FREE_AP_AI_READINESS/`.
3. Record your score and maturity level. Do not debate tools yet.

### Hour 2 — Map one slice of AP

1. Pick **one** process slice (recommended first: *invoice exception triage* or *missing goods receipt follow-up*).
2. Use Process Mapping Step 1–4 templates: Observe → Transcribe → Extract → Structure.
3. Produce: one process map, one decision tree sketch, top 10 exception types for that slice.

### Hour 3 — Select and charter one agent

1. Open Agent Library. Match your slice to **one** agent (often Exception Triage or Goods Receipt).
2. Complete an **Agent Charter** at **Level 0 (Observe)** or **Level 1 (Recommend)** only.
3. Define: human owner, exclusions, KPIs, escalation, audit evidence.
4. Schedule shadow-mode review in 2–4 weeks.

---

## Guardrails for week one

| Do | Do not |
|----|--------|
| Start with Observe / Recommend | Enable payment execution |
| Use historical sample of 50–200 invoices | Trust unverified agent outputs in production |
| Log every disagreement with the agent | Expand to 16 agents at once |
| Keep SoD clear (agent ≠ approver ≠ payer) | Promise savings to the board yet |

---

## Success criteria for week one

- [ ] Diagnostic scored and shared with sponsor
- [ ] One process slice mapped
- [ ] One agent chartered at Level 0 or 1
- [ ] Baseline KPIs recorded (exception rate, touch rate, ageing)
- [ ] Control owner named

If any box is unchecked, stop expanding scope.
