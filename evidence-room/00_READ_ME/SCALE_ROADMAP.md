# Evidence Room Scale Roadmap

## Phase 1: AP Digital Product (Current)
- Launch AP Agent OS across 5 tiers ($0 → $2,500)
- Validate demand via Lemon Squeezy
- Build email list via free diagnostic
- Target: 100 Professional sales in first 90 days

## Phase 2: Services Revenue
- Custom Blueprint fulfilment ($1,500-3,000)
- Implementation advisory ($5,000-15,000)
- Workshop facilitation ($3,000-8,000)
- Lead source: Professional and Team purchasers

## Phase 3: Marketplace Derivatives
- Standalone products on Etsy/Gumroad ($9-29 each)
- AP KPI Dashboard, Exception Taxonomy, Control Matrix, etc.
- Acquisition funnel to core bundle — no cannibalisation

## Phase 4: Recurring Subscription
- Evidence Room Platform: agent monitoring, KPI dashboards, governance certification
- $49-199/month per organisation
- Requires validated demand from Phase 1-2

## Phase 5: Horizontal Expansion
- AR Agent OS → Close Agent OS → Treasury → Reconciliations → Controls → FP&A
- Each vertical follows same 5-tier product architecture
- Cross-sell to existing AP customers

## Phase 6: Evidence Room Finance Agent Platform (SaaS)
- Multi-domain agent orchestration
- ERP connectors, agent marketplace, governance engine
- Enterprise pricing ($500-5,000/month)
- Requires 500+ customers and proven implementation patterns
