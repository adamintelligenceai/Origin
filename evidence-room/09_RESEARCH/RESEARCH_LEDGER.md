# Research ledger

**Evidence Room · Internal**  
**Version:** 1.0 · September 2026  
**Rule:** Every statistic in the suite must have a row. If it has no row, delete the statistic.  
**Labels:** `independent` · `vendor` · `ER-framework` · `illustrative`

This ledger is not a customer zip file. Public pages may cite rows. They may not invent new numbers and “add the row later.”

Re-open independent URLs before a public launch. Fees and domain availability move.

---

## How to add a row

Copy the table. Do not overwrite an old row — add `LEDGER-0xx` and mark the old one `superseded`.

| Field | Required |
|---|---|
| ID | Stable |
| Claim (as we may print it) | Exact enough to audit |
| Source | Author / org |
| Date | Of the source, not of our download |
| URL | Canonical if it exists |
| Exact context | Quote or close paraphrase of *their* framing |
| Label | One of the four |
| Used in | File paths |
| Do not | Forbidden misuse |
