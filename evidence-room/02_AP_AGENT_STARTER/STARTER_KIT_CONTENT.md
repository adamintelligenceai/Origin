## Human vs Agent Decision Framework

| Decision | Human | Agent (Level 1-2) | Agent (Level 3+) |
|----------|-------|-------------------|-------------------|
| Payment authorisation | Always | Never | Never |
| Master data changes | Always | Never | Never |
| Fraud determination | Always | Flag only | Flag only |
| Invoice classification | Review | Recommend | Execute within rules |
| PO matching (within tolerance) | Review exceptions | Prepare match | Auto-match |
| Exception triage | Review priority | Classify + recommend | Classify + route |
| Supplier communication | Approve drafts | Draft | Draft (approved templates) |
| Internal follow-up | Approve drafts | Draft | Draft + send (low-risk) |
| Reporting | Review | Generate | Generate + distribute |
| Duplicate detection | Review flags | Flag | Block (with human override) |
