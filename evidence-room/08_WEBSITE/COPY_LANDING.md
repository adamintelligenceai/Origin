## 3. What agentic AP means

**Agentic AP**, as Evidence Room uses the term, is a designed layer of agent roles sitting across your existing AP operation.

An agent here is a written job. It can propose, prepare, classify, flag, or pack work inside a fence. A human still holds release, payment instruction, control override, and the books.

Agentic AP is not:

- your AP automation suite renamed
- a workforce that replaces AP
- a licence to pay
- a claim that invoices are correct
- a fraud product
- a compliance certificate

If a vendor uses “agent” to mean “our workflow engine with a chat window”, keep their software if it is useful — and still design the operating layer they will not write for you.

## 4. Workforce diagram (on-page text)

Caption: Humans hold responsibility. Agents hold a job. Systems hold the record.

```
Executive reader
   purpose · pause authority · operating measures
            │
   ┌────────┼────────┬────────────┐
   ▼        ▼        ▼            ▼
Steward   Control   Review      Agent
owner     owner     / AP ops    (fenced work)
   │        │        │            │
   └────────┴────────┴─────┬──────┘
                           ▼
              Systems of record
              ERP · AP automation · OCR · bank · archive
```

**Steward** — writes and versions the brief; reads the log.  
**Control owner** — owns control objectives and evidence.  
**Review / AP ops** — handles exceptions and human release.  
**Executive reader** — accepts purpose, pause, and measures.  
**Agent** — classify, flag, draft, pack. Never pay, never override, never close.

The OS is the written agreement among these roles.

## 6. Responsibility model

An agent is not in production because it ran once.

It is in production when five objects have owners:

1. **Purpose** — one sentence a controller will sign.  
2. **Fence** — class, amount, vendors, entities, systems.  
3. **Escalation** — states the agent must not resolve.  
4. **Evidence** — what is kept, where, for whom.  
5. **Measure** — operating numbers and a pause rule.

Missing one of the five is how a pilot becomes an unowned process.

Northline Industrial Group (fictional) would not let an agent “pay matched invoices”. It would let *Match-and-flag* prepare a release pack under $5,000 on a named vendor set, with a human release and a pause if fence-breaches appear.

## 8. Governance

Dull on purpose.

- Named steward and control owner
- Versioned brief
- Change request when fence, model, or instructions move
- Scheduled reading of measures
- Pause authority that does not wait for a steering committee

Governance is not a town hall. Governance is the ability to stop.
