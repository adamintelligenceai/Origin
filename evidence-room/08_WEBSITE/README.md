# Website — evidenceroom.ai

Static information architecture and conversion pages for Evidence Room — AP Agent OS.

Open `index.html` in a browser, or from this folder:

```
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.

**Primary CTA:** Assess Your AP Agent Readiness → `diagnostic.html`  
**Secondary CTA:** Explore the AP Agent OS → `ap-agent-os.html`

The diagnostic scores locally in the browser. Production email capture is specified in `../07_LEMON_SQUEEZY/` and `../06_SALES_AND_MARKETING/LEAD_MAGNET_FUNNEL.md`. Do not upload invoices.

Legal pages are working drafts for counsel.
