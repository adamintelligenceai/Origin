# Diagnostic Posts — 10

**Lockup:** EVIDENCE ROOM — AP AGENT OS  
**Job:** Stand-alone short pieces that teach one diagnostic question. Each can run as LinkedIn, a Resources stub, or an email aside.  
**Length:** 180–280 words.  
**Close:** One question the reader can answer without uploading invoices.  
**Commercial density:** one line at most, not every time.

---

## 1 — Do you have agents, or do you have “the AI”?

If the only name in the programme is the vendor’s feature — Copilot, assistant, bot, “AP AI” — you do not yet have a workforce you can govern.

A diagnostic looks for named roles: intake, validation, matching, triage, duplicate-and-anomaly, payment-proposal review, orchestrator. Names allow owners. Owners allow sampling. Sampling allows demotion.

You do not need sixteen names on day one. You need more than one blob.

**Answer without files:** Write the names you actually use. If the list is one word long, you are in Undesigned or Informal on that question.

---

## 2 — Can you open a packet for last Tuesday’s invoice?

Not a chat log. A packet: source, extract, worksheet or coded fail, owner, clock, flag outcome if any.

If the answer is “the model said it was fine,” the diagnostic will not flatter you. Fluency is not evidence. Evidence is reopenable.

**Answer without files:** Pick one invoice from last week from memory. Name three artefacts you could still find. If you cannot, the layer is not inspectable.

---

## 3 — Is autonomy on a register, or in a thread?

Silent promotion is the ordinary accident. A summary agent becomes a drafting agent becomes a parking agent because someone was busy and the tone was confident.

A register lists agent, object types, level in force, last gate passed, owner, next review. If that table does not exist, permission is implied.

**Answer without files:** Who would you email to ask the current level of the matching agent? If the answer is “no one,” you do not have a register.

---

## 4 — Where is payment release written down?

“We would never let it pay” is a value. A control is a sentence in the charter, the swimlane, and the run book: the proposal agent annotates; named humans approve; a named role transmits; the agent is not on the release line.

If the sentence exists only in a kickoff deck, the diagnostic treats the boundary as informal.

**Answer without files:** Point to the document a new joiner would read on Thursday morning. If you cannot point, write it this week — before any model sees a proposal.

---

## 5 — What happens to a duplicate hypothesis?

A serious layer creates a task when a flag fires. A named control owner clears, confirms, or escalates. High-value flags are never self-clearing.

If flags vanish into a dashboard nobody opens, you do not have a duplicate-and-anomaly agent. You have a widget.

This is not fraud detection. It is flag hygiene.

**Answer without files:** How many uncleared flags are sitting somewhere, and who is late? If nobody knows, the diagnostic will mark this red — as hygiene, not as crime.

---

## 6 — Who is A for Orchestrator and for Controls?

“The SSC” is not a name. “Finance” is not a name.

The diagnostic wants two appointments: an AP Process Owner (accountable for work-object state and the orchestrator) and an AP Controls Lead (accountable for flags and for the payment-boundary sentence). Without those, Wave 1 has nowhere to sit.

**Answer without files:** Write two names or role titles. If you write committees, try again.

---

## 7 — Are fail reasons coded?

Free-text exceptions feel human and prevent mix analysis. If every break is a paragraph, Root Cause has nothing to cluster and management has a queue count.

An atlas can start small: missing GR, price, quantity, defective PO, approval path, capture, supplier wait, internal wait, duplicate hypothesis.

**Answer without files:** Could you draw last month’s mix tomorrow morning? If not, you do not lack a model. You lack codes.

---

## 8 — Is model change controlled?

A prompt edit can be a control change. A model-version change can be a control change. Treating either as Slack folklore is how L1 becomes unofficial L2.

The diagnostic asks whether instruction text, model identity, and mapping notes live under change control, with a reviewer who is not the person who edited.

**Answer without files:** Where is last week’s prompt? Who approved it? If the answer is a personal chat, you have configuration without a configuration system.

---

## 9 — Can you see cost per thousand invoices?

Licence, model/token, and exception minutes. Recorded. Not promised to fall.

If the only cost story is a vendor’s “efficiency” slide, the layer’s economics are unofficial. An expensive and wrong agent should be visible enough to retire.

**Answer without files:** Say the three numbers, even roughly. If you can say none, start a spreadsheet before you start a business case.

---

## 10 — Would you invite Audit as observer next month?

Not as operator. Observer. Ten packets. One payment run. The register.

If the honest answer is “we are not ready to be seen,” the diagnostic band is not Designed, whatever the vendor dashboard says. Readiness to be seen is a property of a control environment. Hide-until-perfect is a property of a demo.

**Answer without files:** Put a date on a calendar or admit you will not. Either answer is useful. The unsaid date is not.
