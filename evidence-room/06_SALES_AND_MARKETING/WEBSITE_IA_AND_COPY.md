# METHOD `/method`

## Title tag

Method | Proof before permission

## Meta description

The Evidence Room method: evidence-gated autonomy, sixteen named AP agents, and a human-held payment boundary. Observation is the default.

## Copy

**Eyebrow:** Method

# Proof before permission.

An agent earns the next unit of responsibility only after it has produced the evidence this organisation defined for that unit.

## The ladder

**L0 Observe.** Read, classify, log, shadow-report. People may read the report. They may not treat it as the system of record.

**L1 Recommend.** Propose an action with rationale and evidence. No ERP write. No external send as the company.

**L2 Prepare.** Assemble a complete packet. A human or a downstream control executes. Prepare is not execute.

**L3 Execute within guardrails.** Only a named, pre-approved, low-risk action inside a written limit table. Sampled. Hard stops.

**L4 Managed autonomy.** The same bounded set as L3, reviewed by exception, recertified. Not a new class of work. Not payment.

Default for a new agent is L0 or L1. No agent is commissioned at L3 or L4.

## The rule that does not move

Payment authorisation, bank-file transmission, and vendor bank-detail change are not agent jobs at any level.

## Evidence before execution

A packet typically includes source, extract, worksheet, correspondence, approval log, flag outcome, owner, and clock. Incomplete packets do not travel. Complete packets still do not pay.

## Agents earn responsibility

Promotion is a recorded decision. Demotion is available. An agent that is expensive and wrong is retired, not scaled.

## Language we will not use here

Guaranteed savings. Fraud detection. Compliance as an outcome. Accounting accuracy as a property of a model. Autonomous payment safety. Touchless AP as a commitment.
