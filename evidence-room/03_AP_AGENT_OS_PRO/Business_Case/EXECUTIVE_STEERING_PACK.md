# Executive steering pack

**Product:** Evidence Room — AP Agent OS · Professional  
**Audience:** Steering group (Finance Transformation, Controller, AP Process Owner, Controls, optional Treasury, optional Audit observer)  
**Use:** Run a 45–60 minute steering meeting on the agent layer.  
**Not:** A benefits-realisation theatre. No meeting in this pack exists to “approve the ROI.”

Team licence holders may also use `04_AP_AGENT_OS_TEAM/STEERING_COMMITTEE_TEMPLATES.md`.

---

## 1. Standing membership

| Seat | Role in this layer | Voting on promotions? |
|---|---|---|
| Chair (CAO / Controller / delegated) | Payment and close holds | Yes |
| AP Process Owner | Orchestrator A; wave scope | Yes |
| Controls Lead | Agent 10; language | Yes on flags and demotion |
| Transformation lead | Method; pack quality | Yes on sequence |
| Treasury / Payments Lead | Agent 12 ceiling | Yes on anything payment-adjacent |
| Internal Audit | Observer | No |
| IT / IAM | Access, service accounts | Voice; vote on access exceptions |

Agents do not attend. Vendors attend only for a timeboxed demo review, not for gate decisions.

## 3. Steer 0 — pack (pre-read 6 pages)

1. Maturity sentence and veto list.
2. Human-hold evidence (last payment run; last bank changes).
3. Wave 1 charters (one-line each: owner, objects, level, exclusions).
4. Informal helper list and what was turned off.
5. Two-week shadow design.
6. What will not be discussed: savings target, fraud KPI, compliance certificate.

**Decision asked:** Start L0 on the named path — yes / no / conditions.

**Conditions that are valid:** hours freed for owners; service accounts; Audit date.  
**Conditions that are invalid:** “show 3× ROI first”; “auto-post under $5k.”

| Min | Item | Artefact |

| 15–25 | Sample disagreements | Dual-review sheet |
| 25–30 | Flag outcomes | Agent 10 register |
| 30–35 | Autonomy register changes | Register (should be none silently) |
| 35–40 | Layer cost token | Cost ledger |
| 40–45 | Decisions | Decision log |

No “AI wow” demo slot. If a vendor must be seen, add 15 minutes *after* decisions.

## 6. 30-day control session

Audit (or a designated control reviewer if Audit declines) samples:

- 5 intake packets
- 5 validation fails
- 5 match worksheets
- All open flags
- The last payment run (human path)

They record reconstructability, not an opinion that the organisation is compliant. Transformation does not “fix” packets during the session.

---

## 7. 90-day recertify

For each live agent: stay / promote (if a case exists) / demote / retire. Apply `AUTONOMY_PROGRESSION.md`. Read `NINETY_DAY_PLAN.md` success list. Do **not** add a new success criterion called payback.

If I13 in the business-case model is still a guess, say so. Do not replace the guess with a steering “consensus percentage.”

---

## 8. Papers that may not enter the pack

- A one-cell ROI.
- A fraud-loss estimate attributed to Agent 10.
- Northline figures presented as peers (Northline is fictional).
- A vendor slide that auto-releases payments, unless it is filed under *Refusals*.

---

## 9. Refusal minute (template)

> On [date] the steering group refused [feature / promotion]. Class [A–J]. Reason: [hold / missing gate / language / owner vacant]. The payment sentence remains: humans release.
