**Product:** Evidence Room — AP Agent OS · Professional  
**Use:** Run the meetings the layer actually needs. Cancel any meeting whose only purpose is “AI excitement.”

Steering formats: `Business_Case/EXECUTIVE_STEERING_PACK.md`. Team workshop: `04_AP_AGENT_OS_TEAM/WORKSHOP_AGENDA.md`.

## 2. Exception mix (weekly) — script

1. STOP incidents (2 min).
2. Volume and open-without-owner (3).
3. Code mix vs last week (7).
4. Top five aged items by *person* (8).
5. EX-OTH candidates for new codes (5).
6. Language slips (3).
7. Actions with names (2).

**Ban:** “the AI is learning”; savings; fraud counts.

---

## 3. Operator huddle — talking points

- You work as you do today during shadow.
- A recommendation is not a post and not a pay.
- If a packet is incomplete, stop.
- If someone says “just release it,” name the class and the human.
- Flags are hypotheses. Say “possible duplicate,” not “fraud.”
- You may reject. Rejects are reviewed, not punished.

---

## 4. Charter working session — agenda

| Min | Item |
|---|---|
| 0–10 | Object types: strike until sampleable |
| 10–25 | Duties vs exclusions (read exclusions aloud) |
| 25–35 | Evidence pack |
| 35–45 | Failure detection and rollback |
| 45–55 | Owner / backup confirmation |
| 55–60 | Sign or adjourn with a date |

If exclusions take less than five minutes, they are incomplete.

---

## 5. Notes hygiene

- Attendance, decisions, evidence URIs.
- No production bank details in notes.
- File under the Orchestrator or a controlled share — not a personal chat.
