**Document type:** Facilitation guide + agendas  
**Aligns to:** `Governance/RACI_TEMPLATES.md`, KPI weekly/monthly cadence

## 1. Meeting catalogue

| Meeting | Cadence | Duration | Chair (A) | Required |
|---|---|---|---|---|
| Daily stand-up | Daily | 10–15 min | AP Manager | Specialists; Tech on-call as needed |
| Weekly agent performance | Weekly | 30–45 min | AP Manager | Prompt Steward; Tech Owner |
| Monthly control & risk | Monthly | 45–60 min | Controller | AP Manager; Audit (C); Security as needed |
| Steering | Monthly or quarterly | 45–60 min | CFO/VP Finance or delegate | Controller; AP Manager |
| Autonomy board | Quarterly if L4 | 45 min | Controller | Audit; Treasury; AP Manager |
| Pilot huddle | Daily during pilot | 15 min | AP Manager | Pilot rota |

---

## 2. Daily stand-up agenda

1. Gate breaches in last 24h (Red first)  
2. Aged exceptions / SLA risks (top 5)  
3. Agent incidents / kill-switch health  
4. Blockers (access, defects)  
5. Owners for today’s actions  

**Parking lot** for redesign ideas — do not redesign live.

**Output:** Updated action list in shared tracker.

---

## 3. Weekly agent performance agenda

**Pre-read:** `WEEKLY_AGENT_PERFORMANCE_REPORT.md` circulated ≥2 hours prior.

1. Portfolio heat strip (5)  
2. Quadrant D gate deep dive (5)  
3. Red/Amber agents (15)  
4. Taxonomy movers / root causes (5)  
5. Promotion/demotion pipeline (5)  
6. Decisions & actions (5–10)  

**Rules:** No vanity metrics. Challenge STP vs FN. Record decisions.

---

## 4. Monthly control & risk agenda

1. Control breach & audit exception log  
2. Risk register movements  
3. Access / SoD certification status  
4. Model/prompt change summary  
5. BCP / fallback gaps  
6. Attestation readiness  

**Output:** Controllers’ notes + actions into risk register.

---

## 5. Steering committee agenda

1. Outcomes vs baseline (STP, exception, cycle, CPI trend)  
2. Industry context (optional one slide: Ardent 2025 peers/BIC)  
3. Investment vs validated benefits  
4. Risk posture & major decisions (levels, funding)  
5. Ask  

Commercial reference if licensing discussed: Free **$0**; Starter **$79**; Professional **$199**; Team **$499**; Custom Blueprint **$1,500–$3,000**.

Use `EXECUTIVE_STEERING_PACK.md` / `BOARD_CFO_SUMMARY.md`.

## 6. Facilitation norms

| Norm | Practice |
|---|---|
| Evidence over opinion | Cite run_ids, scores, samples |
| One Accountable | End every action with named owner + date |
| Timebox | Parking lot ruthlessly |
| Challenge culture | Ask “what would falsify this Green?” |
| No surprise autonomy | Level changes only via pipeline |
