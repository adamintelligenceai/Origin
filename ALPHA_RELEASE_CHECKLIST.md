# Alpha release checklist

Every gate must be checked before inviting 5–10 people.

- [ ] Signed, updateable desktop builds
- [ ] Privacy onboarding copy reviewed
- [ ] Data-flow explainer on `/trust`
- [ ] Local diagnostic export excludes content and secrets
- [ ] Support process documented
- [ ] Incident runbook published internally
- [ ] Usage/cost guardrails in ModelGateway
- [ ] Activation metrics use the fixed telemetry enum only
- [ ] Feature kill switches exist in the control plane
- [ ] Google scopes have not been widened for onboarding convenience
- [ ] No general-purpose web browser agent
- [ ] Wipe, revoke and pairing recovery story disclosed
