# Complete this before work starts

See `00_SERVICE.md` for the full list. Minimum to accept an order:

1. Employee count band and number of legal entities  
2. ERP(s) and any AP automation already live  
3. Monthly invoice volume (evidenced)  
4. AP FTE and whether payment release is in the same team  
5. Exception rate or a honest “unknown”  
6. Twenty sanitised exception snippets  
7. Cannot-touch list  
8. Data residency constraint  
9. Named sponsor and Head of AP  
10. Which band: $1,500 written / $2,500 + readout / $3,000 multi-entity  

Incomplete packs are returned, not guessed.
