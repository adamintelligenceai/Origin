**Product:** Evidence Room — Custom Blueprint

## 1. Pack contents (always)

| # | Deliverable | Description | Format |
|---|-------------|-------------|--------|
| 1 | **Executive summary** | 2–3 pages: problem, principles, slice, ceiling, agents, asks, non-claims | MD/PDF |
| 2 | **Current-state synthesis** | Pains, diagnostic shape, system context, findings (including unknowns) | MD/PDF |
| 3 | **Target operating model sketch** | Responsibility ladder application; human vs agent grid for slice | MD/PDF |
| 4 | **Exception design** | Adopted code list; ownership matrix; top-5 effort codes; SLA drafts | MD + table |
| 5 | **Agent backlog & charters** | Prioritised backlog; full charters for in-band agents; stubs for next | MD |
| 6 | **Control & payment boundary brief** | Auth map; bank-change; SoD notes; hard stops; kill-switch | MD |
| 7 | **KPI & baseline worksheet** | Definitions; populated values or explicit unknowns; measurement plan | MD/XLSX |
| 8 | **90-day implementation plan** | Phases, owners, gates, RAID starter | MD |
| 9 | **Decision log** | From readout (or draft awaiting readout) | MD |
| 10 | **Appendix** | Interview themes (sanitised); glossary; Evidence Room product map | MD |

## 2. Band-specific additions

### Focused (US$1,500)
- Charters for **≤3** agents  
- Single entity / single primary channel  
- Taxonomy for codes in scope (may reference full list)  
- Readout 60 min  

### Standard (US$2,250)
- Charters for **≤5** agents  
- Multi-channel notes within one entity  
- Control brief deepened (A10/A12 emphasis)  
- Steering ToR draft (short)  
- Readout 75–90 min  

### Extended (US$3,000)
- Charters for **≤5** + **sketch cards** for up to 3 more  
- Multi-entity variance section (what differs / what must standardise)  
- Training outline localised to client role titles  
- Change messaging draft (sponsor + AP note)  
- Maturity score baseline  
- Readout 90 min + optional 45 min working session

## 3. Charter minimum fields (each full charter)

- Agent ID/name · purpose · scope in/out  
- Responsibilities · exclusions (hard)  
- Inputs/outputs · systems  
- Owner · RACI · escalation  
- Autonomy now/ceiling · promotion evidence needed  
- Exception codes touched · KPIs · logging  
- Failure handling · change control pointer  

---

## 4. Acceptance criteria (client)

The pack is accepted when:

1. Pilot slice is unambiguous  
2. Autonomy ceiling and payment boundary are explicit  
3. Each in-scope agent has a usable charter (not a slogan)  
4. Exception ownership covers top effort codes  
5. KPI sheet distinguishes measured vs unknown  
6. 90-day plan has named owners for each phase  
7. No banned claims appear in executive summary  
8. Decision log captures readout outcomes (or scheduled date)  

Minor typos do not block acceptance; missing payment boundary language does.
