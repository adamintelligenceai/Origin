# Evidence Room — Custom Blueprint

## 03 — Deliverable outline

**Product:** Evidence Room Custom Blueprint  
**Version:** 1.0  

This is the **table of contents and section standard** for every Custom Blueprint delivered to a buyer. Fulfilment populates it. Square brackets are buyer-specific. The file the buyer receives should be titled `BLUEPRINT_[buyer]_[slice]_[date].md` (or PDF) and stored in **their** Evidence Room.

Every populated section must still answer **what / how / who / wrong / control / measure / evidence** where work is specified.
