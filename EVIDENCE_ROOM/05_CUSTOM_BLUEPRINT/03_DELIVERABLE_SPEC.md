# Custom Blueprint — Deliverable Specification

**Evidence Room** · Acceptance criteria for client packs

## Package structure (delivered folder)

```
ER-CUSTOM-[ClientAlias]-[YYYYMMDD]/
  00_Engagement_Summary.md
  01_Operating_Model_Addendum.md
  02_Agent_[Name]_Blueprint.md   (×1–3)
  03_Controls_and_SoD_Notes.md
  04_Pilot_Plan_60_90.md
  05_Walkthrough_Agenda.md
  06_Revision_Log.md
```

## Per-agent blueprint — required sections

1. Purpose & non-purpose  
2. Invoice classes in / out of scope  
3. Stage path and promotion criteria  
4. Inputs / outputs (system objects named)  
5. Decision logic (rules + model assists — plain language)  
6. Human gates and RACI  
7. Forbidden actions  
8. Evidence schema (fields retained)  
9. Failure modes & monitoring  
10. Test cases (happy path + 5 negatives)  
11. Pilot KPI set (primary, secondary, control)  
12. Kill-switch procedure  

## Engagement summary — required sections

- Context (volume, systems) — no confidential bank data  
- Maturity snapshot  
- Objectives as stated by client  
- Scope boundaries & fee band  
- Explicit disclaimer: no guaranteed financial outcomes  

## Acceptance

Client accepts when:

1. All required sections present  
2. Walkthrough completed or waived in writing  
3. Revision window closed or changes delivered  

## File standards

- Markdown or PDF derived from Markdown  
- Palette for any designed pages: ink `#0B1F2A`, paper `#F7F4EE`, amber `#C47A2C`, teal `#1F5C5C`  
- Filename hygiene: no spaces preferred; no PII in filenames
