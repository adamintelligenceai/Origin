# Implementation Checklist

**Evidence Room** · Starter

Print or copy into your project tracker. Every unchecked money-path item is a stop.

## A. Governance

- [ ] Sponsor and AP Lead named
- [ ] Charter board invite list set
- [ ] Kill-switch owner and procedure documented
- [ ] Claims review: no guaranteed savings/fraud/ROI language in decks

## B. Controls

- [ ] C1 SoD confirmed for pilot path
- [ ] C2 Vendor bank dual control confirmed
- [ ] C3 Audit trail writable for agent actions
- [ ] D1 Vendor payment fields quality checked for pilot vendors
- [ ] Payment release remains human-executed

## C. Data & systems

- [ ] Read access provisioned (least privilege)
- [ ] Non-production environment available for dry-run
- [ ] Invoice class filter testable
- [ ] Evidence storage path with retention policy
- [ ] Clock/timezone standards agreed for cycle-time KPIs

## D. People

- [ ] Processors briefed on responsibility ladder
- [ ] Exception owners mapped
- [ ] Escalation contacts published
- [ ] Feedback channel for false positives

## E. Measurement

- [ ] Baseline KPI worksheet completed
- [ ] Primary, secondary, control KPIs chosen
- [ ] Sample size for QA defined
- [ ] Review calendar invited

## F. Go-live (Propose stage)

- [ ] Shadow results reviewed
- [ ] Known failure modes listed
- [ ] Support hours covered for first two payment cycles
- [ ] Rollback: disable agent without breaking AP ops

## G. Post-week-1

- [ ] Incident log empty of Sev-1 / plan for any Sev-1
- [ ] Disagreement codes trending reviewed
- [ ] Charter amendments versioned
