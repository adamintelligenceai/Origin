# What you bought

Evidence Room AP Agent OS is an operating system for designing, governing and measuring AI agents across Accounts Payable.

It does not replace your ERP, AP automation platform, bank, or AP team. It gives Finance a shared language, a method, and the artifacts required to put agents to work without losing control.

A purchaser should be able to start on Monday.

# Monday sequence (Professional)

1. Read this file and the Quick Start (30 minutes).
2. Complete the readiness diagnostic with the AP manager in the room (60–90 minutes).
3. Pick **one** bounded process (example: missing goods receipts on PO invoices).
4. Map it with the Observe → Extract → Structure templates.
5. Write one Agent Charter at Level 0 or Level 1.
6. Define three controls and four KPIs before any tool is switched on.
7. Collect 50–100 historical cases for a dry test.
8. Brief the CFO with the one-page summary template.

Do not start with sixteen agents. Start with one exception class that is frequent, expensive, and measurable.
