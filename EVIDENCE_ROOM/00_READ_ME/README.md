# Evidence Room — AP Agent OS

**House:** Evidence Room  
**Product:** AP Agent OS  
**Domain:** evidenceroom.ai  
**Brand idea:** Proof before permission.  
**Tagline:** Agents earn responsibility. Evidence decides.

This archive is the operating system for building, governing and scaling AI agents across Accounts Payable. It does **not** replace the AP stack you already run. It designs the agent layer that operates across it.

Full autonomy is not the default. Agents start at **L0 Observe**. They earn each level with evidence. Payment release, vendor bank-change, policy exceptions, and legal disputes stay human.
