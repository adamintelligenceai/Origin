## 1. North star sequence

```
AP digital products (now)
        ↓
Productised services (Blueprint + facilitation)
        ↓
Subscription / membership (operating updates + community light)
        ↓
Finance Agent Platform (later: AR · Close · Treasury · Controls · FP&A)
```

Each stage must reinforce **Operating Evidence** — not drift into autonomous payment software or generic “AI for finance” hype.

---

## 2. Stage A — AP digital product (current)

**Offer ladder (fixed)**  
Free Diagnostic → Starter US$79 → Professional US$199 → Team US$499  

**Jobs**
- Immediate near-zero marginal cost revenue  
- Category ownership: AP agent operating layer  
- Email list + LinkedIn authority  

**Exit criteria to lean harder into services**
- Repeatable Professional conversions from Diagnostic  
- Qualitative proof Controllers finish Friday→Monday path  
- Support load understood  

**Do not** build SaaS in this stage.

---

## 3. Stage B — Productised services

**Offer:** AP Transformation Blueprint US$1,500–3,000 (+ optional facilitation add-ons)  

**Jobs**
- Monetise complexity (multi-entity, control-heavy)  
- Learn edge cases that improve digital packs  
- Qualify demand for larger transformation partnerships  

**Guardrails**
- SOW-scoped; not open-ended SI  
- No autonomous payment implementation positioning  
- Background IP retained; client-specific deliverables per SOW  

**Capacity model:** Limited Blueprint slots/month to protect quality.

---

## 4. Stage C — Subscription layer

**Possible offer (future):** Evidence Room Operating Membership

**Pricing hypothesis (NON-EVIDENCE):** US$29–79/month or annual equivalent — validate later.  

**Rule:** Subscription complements Professional/Team; does not replace the US$199 OS purchase as the core artefact.

---

## 5. Stage D — Finance Agent Platform (later)

**Expand domain modules** using the same OS pattern:

| Module | Agent operating focus (later) |
|---|---|
| AR | Cash application, disputes, collections assists — human cash decisions |
| Record-to-Report / Close | Checklist agents, recon assists, evidence packs |
| Treasury | Observability & prep — **no unsupervised fund movement** |
| Controls / SOX evidence | Control testing assistants with human sign-off |
| FP&A | Narrative and variance prep — not “AI CFO” theatre |

**Platform principles**
1. Same responsibility ladder L0–L4  
2. Same exception OS pattern  
3. Same payment/fund-movement human gate analogue per domain  
4. ERP-agnostic operating layer first; software second (if ever)

**Build trigger (examples — revise with data)**
- Strong AP brand + recurring revenue  
- Clear multi-module demand from Blueprint clients  
- Capital / capacity for multi-year product  

Until then: **AP-only depth beats shallow multi-domain.**
