# START HERE — Evidence Room / AP Agent OS

**Brand idea:** Proof before permission.  
**Line:** Agents earn responsibility. Evidence decides.  
**Default level:** L0 Observe  
**Do not:** stand up sixteen agents, grant L3 in a kickoff, or upload production invoices back to Evidence Room.

Open this file first. The path is **01–12**. Each step names the file to open next. If you skip to Agent 12 because payments are painful, you have left the product.

1. Read `LICENCE.txt` in the zip root. Note your class: Individual, Professional, or Team.  
2. If you have not run the diagnostic, do it without production files: https://evidenceroom.ai/diagnostic — the instrument also lives in `../01_FREE_AP_AI_READINESS/`.

## 01 — Know what you bought

**What to do.** Understand the object. This is an operating system for the *agent layer* across Accounts Payable. It does not replace SAP, Oracle, D365, NetSuite, Workday, Coupa, Tipalti, or your team.

**Open:** `README.md` (this folder) → `../03_AP_AGENT_OS_PRO/Agent_Library/00_AGENT_STACK_OVERVIEW.md`

**Done when.** You can say, in one sentence, what the OS is and what it is not.

## 09 — Freeze the baseline

**What to do.** Count *your* invoices on the slice. First-pass yield, cycle time (one clock), exception mix, unit cost ingredients. Do not paste APQC, Deloitte, or Hackett figures into the scorecard.

**Open (Pro/Team):** `../03_AP_AGENT_OS_PRO/KPI_and_Measurement/00_KPI_FRAMEWORK.md`

**Done when.** The baseline is dated and scoped. TARGET labels are honest.
