## Minute 35–42 — Baseline question

From *your* system, for that slice, last month (or last 100 invoices):

- How many received?  
- How many posted or parked for payment with no exception?  
- How many possible duplicates did a human already catch?  
- What clock do you use for cycle time?

Write the numbers. If you cannot, that is the first work — not a model.

Do not copy $0.38 / $0.92, 63%, or 60% touchless into this box. Those are other organisations’ research, not your baseline.
