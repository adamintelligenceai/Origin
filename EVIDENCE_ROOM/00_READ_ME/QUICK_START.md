# Quick Start — Evidence Room

## If you are a buyer evaluating AP agent readiness

1. Open `01_FREE_AP_AI_READINESS/00_START_HERE.md`
2. Complete the diagnostic questionnaire (35 questions)
3. Score yourself with the rubric → maturity level 1–5
4. Fill the baseline KPI worksheet using your own data
5. Use the business-case starter to frame a conversation with finance leadership
6. If you want blueprints next, purchase **AP Agent Starter ($79)**

## If you are implementing Starter

1. Open `02_AP_AGENT_STARTER/00_START_HERE.md`
2. Align on the operating model and human-vs-agent framework
3. Pick 2–3 agents from the Top 10 blueprints for a controlled pilot
4. Follow the implementation checklist and 90-day transform roadmap
5. Escalate to Pro/Team or Custom Blueprint when scope expands

## If you are fulfilment / custom services

1. Read `05_CUSTOM_BLUEPRINT/00_SERVICE_BROCHURE.md`
2. Send `01_INTAKE_QUESTIONNAIRE.md`
3. Run `02_FULFILMENT_WORKFLOW.md`
4. Deliver against `03_DELIVERABLE_SPEC.md`

## If you are marketing / web

1. IA: `08_WEBSITE/00_IA_AND_NAV.md`
2. Home + pricing + method pages in `08_WEBSITE/`
3. Conversion landing: `06_SALES_AND_MARKETING/Landing_Page/01_AP_LANDING_PAGE.md`
4. Email + LinkedIn + content engine under `06_SALES_AND_MARKETING/`
