# Workshop Facilitation Guide — AP Agent OS Team

**Evidence Room** · Team · Workshop  
**Facilitator:** Programme lead or external Custom Blueprint facilitator  
**Brand:** ink `#0B1F2A` · paper `#F7F4EE` · amber `#C47A2C` · teal `#1F5C5C`

## Purpose

Move a cross-functional group from “we should try AI in AP” to a **named pilot charter**, **baseline KPIs**, and **Phase 0–2 exit criteria** — without promising savings or fraud outcomes.

## Pre-work (mandatory)

| Owner | Deliverable | Source |
|---|---|---|
| Programme lead | Stakeholder map + invite list | This guide §Roles |
| AP lead | Completed process-owner questionnaires | `04_PROCESS_OWNER_QUESTIONNAIRES.md` |
| Facilitator | Interview synthesis (1–2 pages) | `03_STAKEHOLDER_INTERVIEW_GUIDE.md` |
| Controller / Controls | Hard-gate self-check (money path, SoD, bank change) | Free kit / Pro governance |
| All attendees | Read one-pager: earn-up stages + disclaimers | Deck slides 3–6 |

**Do not start** if money-path hard gates fail and the room intends Propose/Execute stages. Keep Observe/Draft only.

| Role | Count | Job in workshop |
|---|---|---|
| Facilitator | 1 | Timebox, capture decisions, enforce claims discipline |
| Sponsor | 1 | Decide risk appetite and pilot funding |
| AP process owner | 1–2 | Ground truth on exceptions and volume |
| Processor / exception specialist | 1–2 | Reality-check agent boundaries |
| Controls / Internal Audit | 1 | Evidence and SoD constraints |
| IT / Security | 1 | Tooling and data feasibility |
| Procurement (optional) | 0–1 | PO quality and supplier friction |
| Scribe | 1 | Decision log + parking lot |

## Claims rules for facilitators

1. Cite Ardent 2025 only as **industry context**: cost **$9.84** / invoice; exception **18.4%**; STP **35.4%**.
2. Label every business-case number **illustrative** unless it is the client’s measured baseline.
3. Ban: “guaranteed savings,” “autonomous AP,” “replace Coupa/Tipalti,” “AI decides payments.”
4. Every candidate agent needs a **human owner** before it leaves the room.

## Facilitation tactics

### Timeboxing
Use a visible timer. Parking lot for policy debates longer than 5 minutes.

### Conflict patterns

| Pattern | Facilitator move |
|---|---|
| “AI will cut cost to BiC” | Redirect to client baseline; Ardent BiC is **their** cohort, not a product promise |
| IT wants broad write-back day one | Cap stage at Recommend until shadow evidence exists |
| Audit wants zero agents | Offer Observe-only pilot with evidence pack design — still valuable |
| AP wants payment agent | Hard no on payment release; Payment Proposal Review stays recommend-only |

### Capture format (decision log)

```
Decision ID:
Date:
Topic:
Decision:
Stage ceiling:
Owners:
Evidence required:
Review date:
```
