# Workshop Facilitation Guide

**Product:** Evidence Room — AP Agent OS Team  
**Document ID:** `ER-TEAM-WS-FAC`  
**Version:** 1.0  
**Audience:** Facilitator / Finance Transformation lead  
**Companion:** Workshop deck, exercises, interview guide, PO questionnaire

---

## 1. Purpose

Run a credible, executive-grade AP Agent Operating Model workshop that produces **decisions and artefacts**, not inspiration.

Success = Controllership will put their name on an autonomy ceiling and payment boundary; AP will own a pilot slice; IT understands logging and change control.

## 6. Half-day compress

**Audience:** Sponsor + Process Owner + Controller + 2 AP leads + IT  
**Duration:** 3.5–4 hours  

1. Principles + ceiling (40m)  
2. Taxonomy top-10 codes only (40m)  
3. Pick 2 agents + exclusions (50m)  
4. Payment boundary + risks (30m)  
5. 90-day skeleton + asks (40m)  
6. Close decisions (20m)  

Skip deep charter drafting; schedule Design working session within 5 days.

## 7. Facilitation techniques

### 7.1 The “evidence test”
When someone asserts improvement potential, ask: *What baseline number exists today, in which report, owned by whom?* If none → capture as finding, not benefit.

### 7.2 The “payment line”
Any suggestion that crosses authorisation → redirect to A12 prepare-only. Do not workshop workarounds in public.

### 7.3 Time boxes
Use visible timers. When debate exceeds box, park with owner and date.

### 7.4 Two-vote prioritisation
For agent backlog: each participant gets 3 votes (dot). Break ties with Controller risk lens, not loudest voice.

### 7.5 Disagreement protocol
Write both options; decide with named authority; record dissent without drama.

## 8. Handling difficult personas

| Persona | Pattern | Move |
|---------|---------|------|
| Hype champion | “Autonomous AP by Q3” | Re-read hard stops; ask Controller to speak |
| Fear veto | Blocks all pilots | Offer L0 shadow only; show kill-switch |
| ERP nostalgic | Turns session into vendor RFP | Parking lot; restate OS vs stack |
| Hero processor | “Only I know the work” | Pair on taxonomy; make them owner of codes |
| IT purist | Wants platform first | Agree logging/access spikes; defer build vs buy |
| Savings hunter | Demands $ slide | Open NON-EVIDENCE tracker; refuse guarantee |

## 9. Artefact quality checklist (exit)

- [ ] Decision log complete with names/dates  
- [ ] Autonomy ceiling written  
- [ ] Payment boundary initialled by Controller/sponsor  
- [ ] Pilot slice defined (entity × channel × category)  
- [ ] ≤5 agents prioritised; ≤3 for first shadow  
- [ ] Exception codes adopted for slice with owners  
- [ ] KPI list with data owners (even if values TBD)  
- [ ] 90-day phases with workstream owners  
- [ ] Kill-switch owner named  
- [ ] Next steering date set  
- [ ] Banned claims respected in readout deck  

If more than two items missing, schedule a 90-minute cleanup — do not pretend the workshop finished.
