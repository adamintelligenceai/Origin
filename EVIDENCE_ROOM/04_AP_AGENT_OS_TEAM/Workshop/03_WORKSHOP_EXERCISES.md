## Exercise 1 — Pain & readiness (25–40 min)

### Objective
Ground the room in current-state pain and a shared readiness shape; select a pilot slice.

### Materials
Diagnostic scores (if any); sticky notes; slice definition card.

### Steps
1. **Silent pain storm (5 min):** Each person writes 3 AP pains (one per note).  
2. **Cluster (7 min):** Group into Process / Data / Controls / Exceptions / Talent / Culture.  
3. **Rapid score (10 min):** If no pre-work, pods score each dimension 0–100 gut with evidence notes. If pre-work exists, validate or challenge.  
4. **Slice pick (8 min):** Choose entity × channel × category for pilot. Write volume estimate.  
5. **Report (5 min):** One spokesperson: top cluster, weakest dimension, proposed slice.

### Output
| Field | Result |
|-------|--------|
| Top pain cluster | |
| Weakest dimension | |
| Pilot slice | |
| Autonomy hypothesis | L0 / L1 |

### Facilitator key
Kill solution ideas (“we should buy X”). Capture them on parking lot. Ensure slice is narrow enough to finish in 90 days.

## Exercise 2 — Install taxonomy (60–75 min)

### Objective
Adopt major codes for the pilot slice; assign owners and draft SLAs; identify top 5 by effort.

### Materials
Condensed code list (Starter §4 / Pro taxonomy); ownership matrix template.

### Steps
1. **Walk families (10 min):** Facilitator overviews code families.  
2. **Adopt/adapt (20 min):** For each major code, mark Keep / Rename locally / Out of scope for slice. Prefer Keep.  
3. **Owners (15 min):** Assign primary owner role + backup for top 12 codes.  
4. **Effort vote (10 min):** Dots on codes consuming most hours.  
5. **SLA draft (10 min):** For top 5, draft hours to first touch and to resolve.  
6. **Stress test (10 min):** Controllership challenges `duplicate_*` and `banking_change_concern` paths.

### Output
- Annotated code list  
- Ownership matrix (draft)  
- Top 5 codes by effort  
- Open policy questions list  

### Facilitator key
Do not invent 40 boutique codes. Prevent Procurement from rejecting all PO-related ownership.

## Exercise 3 — Prioritise agents & draft charters (60–75 min)

### Objective
Build Need × Readiness heatmap; select ≤3 pilot agents; draft job + exclusions + owner.

### Materials
Agent family cards; charter one-pager template; voting dots.

### Steps
1. **Heatmap (15 min):** Score Need 1–5 and Readiness 1–5 per family.  
2. **Vote (10 min):** Select ≤5 backlog; star ≤3 for first shadow.  
3. **Charter draft (30 min):** Pods draft for their assigned agent: purpose, does/does not, owner, L0/L1, KPIs.  
4. **Gallery (10 min):** Peer critique — especially exclusions.  
5. **Plenary lock (10 min):** Confirm pilot three; park the rest.

### Output
| Agent | Owner | Ceiling | Top 3 exclusions | First KPI |
|-------|-------|---------|------------------|-----------|
| | | | | |
| | | | | |
| | | | | |

### Facilitator key
Reject A12 if anyone writes “auto-release under threshold.” Reject A10 if “guarantees no duplicates.”

## Exercise 4 — Governance, ceiling, risks (45–60 min)

### Objective
Sign autonomy ceiling; name kill-switch; draft risk register.

### Materials
Hard stops slide print; risk template; decision log.

### Steps
1. **Ceiling (10 min):** Sponsor + Controller propose ceiling for 90 days. Room challenges. Record.  
2. **Payment boundary (10 min):** Read aloud; initial.  
3. **Kill-switch (5 min):** Name human who can pause agents.  
4. **Risk brainstorm (15 min):** Each pod adds 3 risks (likelihood × impact qualitative).  
5. **Treatments (15 min):** Assign owners for top 5 risks.  
6. **SoD spot-check (5 min):** Confirm agent prepare does not collapse post vs pay.

### Output
- Signed ceiling + boundary  
- Kill-switch owner  
- Risk register v0 (top 5)  

### Facilitator key
If Controller refuses to sign, stop “transformation” language — document blocker and move to L0-only path.

## Exercise 5 — 90-day plan & RACI (45–60 min)

### Objective
Build a real plan with owners and checkpoints.

### Materials
Roadmap board template; RACI wall.

### Steps
1. **Phase columns (5 min):** Foundation / Design / Shadow / Pilot / Decide.  
2. **Card storm (15 min):** Write work items (one card each).  
3. **Place & prune (10 min):** Must-fit in 90 days only.  
4. **Owners (10 min):** Every card gets R and A.  
5. **Checkpoints (10 min):** Define Day 30 / 60 evidence reviews.  
6. **Dependency lines (5 min):** IT access, taxonomy live, baseline extract.

### Output
- Roadmap board photo/export  
- RACI for 6–10 workstreams  
- Checkpoint calendar  

### Facilitator key
Remove cards with no owner. Remove “deploy 16 agents.”

## Optional Exercise 6 — Executive readout rehearsal (20 min)

### Objective
Practice a 5-minute CFO brief without banned claims.

### Script structure
1. Problem (30s)  
2. Principles + ceiling (45s)  
3. Pilot slice + agents (60s)  
4. KPIs we will baseline (45s)  
5. Risks & asks (60s)  
6. What we will not claim (30s)  

### Scoring (peers)
Clarity · Control literacy · No hype · Clear ask — each 1–5.

## Answer keys (facilitator — not distributed)

**Ex1 good slice examples:** Single company code + email channel + PO goods; or shared services queue for one category.  
**Ex1 bad slices:** “All global AP”; “every vendor.”  

**Ex2 non-negotiable keeps:** `potential_duplicate`, `duplicate_invoice`, `banking_change_concern`, `doa_issue`, `missing_receipt`.  

**Ex3 sequencing heuristic:** Taxonomy/A04 → intake/validation or A10 → chase agents → match assist → A12 prepare.  

**Ex4 minimum ceiling:** L1 for 60–90 days for first programme is default recommendation.  

**Ex5 Day 30 evidence:** Codes in tracker; baselines pulled; charters approved; read access proven.
