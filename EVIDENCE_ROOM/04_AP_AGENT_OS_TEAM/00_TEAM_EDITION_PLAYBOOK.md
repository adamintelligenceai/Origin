### What Team Edition is

Professional OS is the **rulebook**. Team Edition is the **way a group of humans adopts the rulebook**: workshop, interviews, training, steering, benefits tracking, maturity, and change communications.

You can run a one-day workshop from this pack tomorrow **if** you have: a named AP Accountable, a room (or video) for 8–16 people, exported volume/exception samples (even imperfect), and a first-slice hypothesis. You cannot leave the day with a live executing agent — and you should not try.

## 1. What to do with this pack

1. Appoint a **Transformation lead** (Responsible for the pack) and a **Head of AP** (Accountable for AP outcomes).  
2. Run pre-workshop interviews (2–5 days).  
3. Run the one-day workshop; leave with a signed first-slice and a 30-day evidence plan — not a slogan.  
4. Train the floor before Shadow.  
5. Install steering and a benefits register that cannot accept unsigned cash.  
6. Re-assess maturity each quarter.  
7. Promote agents only through Professional gates.

**How.** Sequence in §3.

**Who.**

| Role | Team Edition duty |
|---|---|
| CFO / FD | Sponsor; L3+ / payment-adjacent acknowledgement |
| Controller | Financial claims; cost model |
| Head of AP | Operating Accountable |
| Transformation lead | Workshop, tracker, comms cadence |
| AP Manager | Daily evidence after Test |
| Control owner | Veto on risk-control |
| Change lead | Toolkit and floor messaging |
| Finance Systems | Identities and hashes |
| Internal Audit | Informed; may observe workshops |
| Agent | Never Accountable |

**Wrong.** “Centre of Excellence” owns the agent; AP is a passenger. Vendor success manager as owner.

**Control.** RACI from Professional. Incumbents on the tracker.

**Measure.** Workshop outputs filed; training completion before Shadow; steering packs with dictionary IDs.

**Evidence.** `[BUYER]/Evidence/Team/` plus Professional folders.

## 2. Outcomes Team Edition is allowed to claim

**Allowed:** We named owners. We froze a slice. We produced a current-state gap list. We trained N people. We have a Test pack ID. We held Shadow for N days. We decided Hold.

**Not allowed:** Guaranteed savings. “Autonomous AP.” “Fraud-proof.” “Compliant by design.” “Board-ready ROI” without Controller validation.

Context research (not our results): Deloitte 8 Oct 2025 — 63% AI deployed / 21% measurable ROI; Hackett Nov 2025 — software-adopter 60% touchless / 3.5× productivity at ≥30% touchless. Use only as labelled context in executive papers.

## 4. Workshop-in-one-page (detail in Workshop/)

**Object of the day:** a first-slice pack the Accountable will sign.

**Not the object:** a 16-agent roadmap poster; a savings target; a tool selection bake-off (tools are a later C2 with privacy).

**Must-produce artefacts by 17:00**

1. Slice allow-list  
2. Human-class confirmation  
3. As-done vs as-written top 10  
4. First agent + L0 charter skeleton  
5. Risk top 8  
6. Baseline metric list (IDs, not targets)  
7. 30-day plan with named R’s  
8. Decision: proceed to Observe completion / Hold / Stop  

**Who in the room (minimum)**

Head of AP, AP Manager, one processor, one exception owner, Control, FinSys, Transformation. Add Procurement and GR if matching/GR is the candidate. Add Treasury if anyone mentions payments.

---

## 5. Training-in-one-page

Processors learn: packet fields, taxonomy, override reason codes, “do not wait in Shadow,” kill-switch, four human classes.

Owners learn: charter checklist, promotion evidence, weekly report, envelope, incident.

Neither course is a prompt-engineering class.

---

## 6. Steering-in-one-page

Monthly (or per gate). Pack order: risk-control → operational → cost → activity last. Conservative business case if still funding. Kill-switch test date. No vendor theatre.

## 8. How you measure Team Edition itself

| Question | Metric |
|---|---|
| Can they run Monday? | First-slice signed; owners named |
| Did the floor hear the rules? | Training attendance before Shadow |
| Is Steer honest? | Unsigned $ lines = 0 |
| Did we over-claim? | Language review of comms |

**Evidence.** Team scorecard quarterly (qualitative + the metrics above).
