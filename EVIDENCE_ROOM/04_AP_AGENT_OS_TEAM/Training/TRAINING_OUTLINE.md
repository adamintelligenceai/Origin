# Four modules × 45 minutes

**1. Language.** Agent, charter, level, taxonomy, evidence, kill switch. Exercise: rewrite a hype sentence into Evidence Room voice.

**2. Reviewing recommendations.** Accept, edit, reject, escalate. How to write an override reason. Exercise: ten sanitised outputs.

**3. Hostile content and privacy.** EX-PIJ. Approved models. No consumer paste. Exercise: the invoice that tries to change the bank.

**4. Scorecard and incidents.** Four metric families. How to stop an agent on a Wednesday. Exercise: fill this week’s tiles with fake but coherent numbers.

# Job aids

One-page: “What I do if the agent is wrong.” One-page: “What I never let the agent do.”
