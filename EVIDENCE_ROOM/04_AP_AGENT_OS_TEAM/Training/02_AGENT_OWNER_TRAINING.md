# Evidence Room — AP Agent OS Team Edition

## Training — 02 Agent owner

**Product:** Evidence Room AP Agent OS — Team Edition  
**Module:** Training  
**Standard:** Proof before permission. Responsibility is earned.  
**Audience:** Named human owners (and deputies) of each agent; AP Manager; Control partner  
**Version:** 1.0  

Owners are **not** prompt tinkerers. They are accountable operators of a charter.

---

## 1. What to do

Run a 4-hour owner course before the owner signs a charter, and a 90-minute **gate clinic** before any promotion request.

**How.** Modules O1–O8. Bring the actual charter draft.

**Who.** Transformation or Head of AP teaches; Control teaches promotion and incidents; FinSys teaches hashes and identities. Owner must attend — a delegate cannot sign later without sitting the course.

**Wrong.** Vendor certification as a substitute. Owner = “the CoE.”

**Control.** Charter checklist completed in-class on their agent.

**Measure.** Owners trained / agents live; promotion requests without Measure pack (should be 0).

**Evidence.** `[BUYER]/Evidence/Team/Training/Owners/`.

---

## 2. Learning objectives

The owner can:

1. Complete and defend a charter against Standard 19.  
2. Explain L0–L4 and the one-increment rule.  
3. Run or supervise Historical labels-first discipline.  
4. Operate Shadow daily sheet and mid-point access.  
5. File a C2/C3 for any behaviour change.  
6. Compile a weekly report with dictionary IDs.  
7. Contain an incident (disable path).  
8. Refuse an unsigned savings line.

## 4. Module notes

### O1 Charter

**What.** Standard 19 is the acceptance test.  
**How.** Fail the draft on purpose (blank exclusions) then fix.  
**Wrong.** Prompt-only charter.  
**Evidence.** Annotated checklist.

### O2 Autonomy

**What.** `01_AUTONOMY_POLICY.md`.  
**How.** Case: sponsor wants L3 Friday — write the refusal.  
**Control.** Payment-adjacent needs CFO/FD acknowledgement.

### O3 Test

**What.** Historical scripts.  
**How.** Write a 10-row coverage matrix including EX-PAY-001 and paid DUP sample.  
**Wrong.** Vendor golden set only.

### O4 Shadow / Pilot

**What.** Modes.  
**How.** Draft a Pilot Charter with a deny-list; facilitator rejects it; rewrite as allow-list.

### O5 Change

**What.** Prompt edit = C2. Model swap = C3.  
**How.** FinSys shows where hashes live (buyer systems).

### O6 Economics

**What.** Case cost = inference + minutes.  
**How.** ACME ILLUSTRATIVE envelope table — not their targets.  
**Wrong.** Turning off Duplicate to save tokens.

### O7 Incident

**What.** Contain first.  
**How.** Fictional: shadow identity sent a supplier mail. First three actions. Gold: disable send, incident record, do not “apologise and continue.”

### O8 Weekly pack

**What.** Four families, no netting.  
**How.** Hand a fake pack with “1,200 AI invoices” headline and an unsigned $ saving. Owners mark defects.

## 5. Gate clinic (90 min, before promotion)

Bring: Measure pack, residual list, access extract, hash match, increment proposal (one dimension).

Walk the promotion checklist. Control owner may stop the clinic and send the pack back.

**Who.** Owner, AP Manager, Control, FinSys.  
**Measure.** Clinic held / promotion.  
**Evidence.** Clinic note attached to change record.
