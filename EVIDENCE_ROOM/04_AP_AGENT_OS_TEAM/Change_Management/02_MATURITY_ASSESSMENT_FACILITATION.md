# Maturity Assessment Facilitation — AP Agent OS Team

**Evidence Room** · Team · Change Management  
**Companion:** Free kit `01_FREE_AP_AI_READINESS/02_MATURITY_MODEL.md`  
**Session length:** 75–90 minutes  
**Output:** Agreed maturity level + agent posture + 90-day safe next steps

## Purpose

Translate diagnostic intuition into a **shared posture** for what agents may do now — without using maturity as a vanity score or a savings promise.

## Preparation

| Item | Owner |
|---|---|
| Free diagnostic scores (if available) | Programme lead |

## Facilitation agenda

| Min | Activity |
|---|---|
| 0–10 | Claims & purpose; ban “we’re Level 5 because we bought AI” |
| 10–25 | Silent self-score by dimension (below) |
| 25–45 | Group calibration — evidence required for each claimed level |
| 45–60 | Map level → agent posture |
| 60–75 | Safe next steps (product + phase) |
| 75–90 | Parking lot + owners |

## Dimension cards (score 1–5 each)

| Dimension | 1 Fragile | 3 Capable | 5 Evidence-ready |
|---|---|---|---|
| Process documentation | Tribal | SOPs exist, uneven use | Lived SOPs + exception taxonomy |
| Measurement | Anecdote | Partial KPIs | Trusted baselines & cadence |
| Controls / SoD | Gaps known | Core holds | Tested + agent-aware |
| Data / master quality | Chronic breaks | Manageable | Actively stewarded |
| Tooling / integration | Inbox-heavy | Core platforms live | Logs & environments usable |
| Change capacity | Firefighting only | Can run a pilot | Can sustain portfolio |

**Method:** Individuals score → reveal → debate outliers with **evidence**, not status.

## Level definitions (facilitator cue card)

| Level | Name | Agent posture |
|---|---|---|
| 1 | Manual & opaque | Observe mapping only |
| 2 | Documented but fragile | Draft/summaries; 100% human action |
| 3 | Controlled operations | Recommend with mandatory confirm |
| 4 | Measurable & integrable | Narrow Execute after earn-in |
| 5 | Agent-ready with governance | Portfolio + continuous control |

## Calibration rules

1. The **lowest material dimension** often caps posture more than the average.  
2. “We have Copilot” ≠ Level 4.  
3. Payment-adjacent ambitions require Controls affirmation regardless of level.  
4. Ardent benchmarks do not move your level. Your evidence does.

## Maturity ≠ benefits

Read aloud:

> Reaching a higher maturity level does not guarantee movement toward Ardent averages (2025 cost **$9.84**, exception **18.4%**, STP **35.4%**). Maturity governs **how safely** you may use agents — not a savings forecast.
