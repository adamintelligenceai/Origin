# Steering Committee Pack — AP Agent OS Team

**Evidence Room** · Executive  
**Cadence:** Monthly (biweekly during Phases 1–4)  
**Chair:** Sponsor (CFO / Controller)  
**Secretary:** Programme lead

## Purpose

Make **promotion, demotion, scope, and risk** decisions with evidence — not slide theatre.

## Standing membership

| Seat | Role | Voting? |
|---|---|---|
| Sponsor | CFO / Controller | Yes |
| AP process owner | AP Director / Manager | Yes |
| Controls | Internal Audit / Risk | Yes (controls matters) |
| IT | Application / platform owner | Yes (tooling matters) |
| Programme lead | Transformation / shared services | Yes |
| Security | IAM / SecOps | Consulted |
| Procurement | P2P | Consulted as needed |
| Treasury | Payments | Required if payment-adjacent |

**Quorum:** Sponsor + AP owner + Controls (or delegate with written authority).

## Agenda template (60 minutes)

| Min | Topic | Owner | Papers |
|---|---|---|---|
| 0–5 | Claims reminder & conflicts | Chair | Slide card |

| 40–50 | Risk & dependency review | Programme lead | RAID |
| 50–55 | Decisions & actions | Secretary | Decision log |
| 55–60 | AOB / next gate date | Chair | — |

## Pre-read pack (48 hours before)

1. One-page status (template below)  
2. KPI strip (definitions frozen)  
3. Charter change requests  
4. Sample evidence excerpts (redacted)  
5. Open CRITICAL/HIGH risks

```markdown
# Agent OS Steering — [Date]

## Stage ceiling (portfolio)
```

## Decision types & authority

| Decision | Authority |
|---|---|
| Observe → Recommend (pilot class) | Steering |
| Recommend → Draft | Steering |
| Draft → Execute (narrow) | Steering + Controls affirmative |
| Expand invoice class | Steering |
| Emergency demotion / kill | Kill-switch owner (ratify at next steering) |
| External supplier send at Draft | AP owner within charter; report monthly |
| Payment release by agent | **Never** under this pack |
