# Implementation Playbook — Phases 0–10

**Evidence Room** · Team · Implementation  
**Companion trackers:** `02_IMPLEMENTATION_TRACKER.md` · `03_BENEFITS_REALISATION_TRACKER.md`  
**Principle:** Agents that earn responsibility.

## How to use

Each phase has **intent**, **entry criteria**, **core work**, **exit criteria**, and **artefacts**.  
Do not skip exit criteria to “move fast.” Demote phase if evidence is weak.

**Claims:** No guaranteed savings/fraud/ROI. Ardent 2025 (cost **$9.84**, exception **18.4%**, STP **35.4%**) = context only.

---

## Phase 0 — Foundation

**Intent:** Align mandate, licence, claims discipline, and owners.

| Entry | Exit |
|---|---|
| Sponsor identified | Written mandate + stage philosophy |
| Team pack available | Seat roster started |
| | Claims checklist acknowledged |

**Core work**

- Name sponsor, programme lead, AP owner, Controls partner, IT partner, kill-switch owner  
- Create Evidence Room folder structure  
- Confirm stack complement posture (no rip-and-replace narrative)  
- Schedule workshop or confirm interview pre-work  

**Artefacts:** Mandate note · Seat roster · Folder stub · Disclaimer acknowledgment

---

## Phase 1 — Discover

**Intent:** Know as-is reality before agents.

| Entry | Exit |
|---|---|
| Phase 0 exit | Interview synthesis complete |
| | Process-owner questionnaires complete |
| | Baseline measurement plan agreed |

**Core work**

- Stakeholder interviews  
- Questionnaires  
- Volume / exception / system inventory  
- Hard-gate self-assessment (payment, bank change, SoD)  

**Artefacts:** Synthesis · Questionnaire pack · Baseline plan · Hard-gate results

---

## Phase 2 — Design

**Intent:** Charter the pilot; freeze stage ceiling.

| Entry | Exit |
|---|---|
| Phase 1 exit | ≥1 approved charter draft |
| Workshop held (or equivalent design sessions) | RACI for pilot activities |
| | KPI definitions frozen |
| | Evidence standard drafted |

**Core work**

- Workshop (half or full day)  
- Agent selection (prefer A01–A10)  
- Promotion/demotion gates drafted  
- Risk assessment started  

**Artefacts:** Charters · RACI · KPI freeze · Risk register v0.9 · Decision log

---

## Phase 3 — Build & historical test

**Intent:** Prove the agent behaves on known samples before live shadow.

| Entry | Exit |
|---|---|
| Phase 2 exit | Historical test script executed |
| Test environment / sample set available | Defects triaged; blockers closed or accepted |
| | Prompt/instruction version pinned |

**Core work**

- Configure tools within charter  
- Run Pro `Testing/01_HISTORICAL_TEST_SCRIPT.md`  
- Fix taxonomy / instruction gaps  
- Security review of access  

**Artefacts:** Test results · Version pin · Access review note

---

## Phase 4 — Shadow mode

**Intent:** Parallel run; humans remain system of record path.

| Entry | Exit |
|---|---|
| Phase 3 exit | Agreement metrics meet gate |
| Training completed for cohort | Evidence packs complete on sample |
| | No CRITICAL incidents open |

**Core work**

- Follow `Testing/03_SHADOW_MODE_METHOD.md`  
- Buddy coaching  
- Weekly performance report live  

**Artefacts:** Shadow scorecard · Training roster · Weekly reports

---

## Phase 5 — Pilot (bounded live)

**Intent:** Narrow Recommend/Draft on approved class only.

| Entry | Exit |
|---|---|
| Phase 4 exit | UAT signed |
| Steering approval | Pilot retrospective done |
| Stage ceiling ≤ agreed | Promote / hold / stop decision recorded |

**Core work**

- `Testing/02_UAT_TEMPLATE.md` + `04_PILOT_METHOD.md`  
- Confirm/reject discipline enforced  
- Incident logging  

**Artefacts:** UAT · Pilot log · Steering decision

---

## Phase 6 — Control prove-in

**Intent:** Satisfy Controls/Audit that evidence and SoD hold under load.

| Entry | Exit |
|---|---|
| Stable pilot ≥2–4 weeks | Controls opinion: Support or Conditional with plan |
| | Sample QA threshold met |
| | Kill-switch drill completed |

**Core work**

- Expanded sampling  
- Evidence completeness audit  
- Tabletop demotion drill  
- Update governance pack  

**Artefacts:** Controls memo · Drill record · Updated gates

---

## Phase 7 — Expand invoice classes

**Intent:** Add classes carefully — not “turn it all on.”

| Entry | Exit |
|---|---|
| Phase 6 exit | Each new class has charter addendum |
| | Fresh shadow or focused UAT per class |
| | Portfolio stage map updated |

**Core work**

- Rank backlog  
- Per-class risk assessment  
- Training delta  
- KPI segmentation by class  

**Artefacts:** Class addenda · Updated tracker

---

## Phase 8 — Multi-entity / shared services scale

**Intent:** Standardise method across entities without ignoring local law/process.

| Entry | Exit |
|---|---|
| Central method stable | Entity rollout plan with local owners |
| | Local hard gates re-checked |
| | Seat licence compliance checked |

**Core work**

- Entity difference log  
- Local training waves  
- Central Evidence Room conventions  
- Steering representation for entities  

**Artefacts:** Entity matrix · Rollout plan · Licence roster

---

## Phase 9 — Optimise & portfolio manage

**Intent:** Treat agents as a portfolio with cost, risk, and adoption — not a science fair.

| Entry | Exit |
|---|---|
| Multiple agents/classes live | Quarterly portfolio review instituted |
| | Underperforming agents demoted/retired |
| | Instruction versions under change control |

**Core work**

- Root-cause themes (A15 pattern)  
- Orchestration boundaries (A16 pattern) — still human-owned outcomes  
- Vendor/tool cost review (your contracts)  
- Refresh illustrative business case with **measured** inputs only  

**Artefacts:** Portfolio review minutes · Change-control log

---

## Phase 10 — Sustain & continuous control

**Intent:** BAU governance; continuous monitoring; research/claims hygiene.

| Entry | Exit (ongoing) |
|---|---|
| Phase 9 exit | Quarterly claims review |
| | Annual control testing plan includes agents |
| | Owner succession plan exists |

**Core work**

- BAU Charter Board  
- Continuous sample QA  
- Access recertification  
- Update playbooks when stack changes  
- Revisit maturity assessment annually  

**Artefacts:** BAU calendar · Control test plan · Succession map
