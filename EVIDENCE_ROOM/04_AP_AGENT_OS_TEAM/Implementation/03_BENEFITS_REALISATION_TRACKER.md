## Benefit validation rules

1. A benefit moves from **Hypothesis → Measured** only with dated extracts.  
2. External benchmarks never count as realised benefits.  
3. If sample QA falls, pause financial illustration storytelling.  
4. Board materials must carry the disclaimer banner.  

## Realisation status codes

| Code | Meaning |
|---|---|
| `IDEA` | Not yet hypothesised rigorously |
| `HYP` | Hypothesis with owner |
| `MEAS` | Measured with evidence |
| `SUST` | Sustained ≥2 periods |
| `DROP` | Abandoned / invalid |

2. Baseline still valid?  
3. HYP → MEAS promotions  
4. Control benefits first  
5. Illustrative financials last (or omit)  
6. Decisions: continue / narrow / stop
