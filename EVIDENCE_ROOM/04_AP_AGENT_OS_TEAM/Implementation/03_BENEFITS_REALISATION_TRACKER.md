# Benefits Realisation Tracker

**Product:** Evidence Room — AP Agent OS Team  
**Document ID:** `ER-TEAM-BEN`  
**Version:** 1.0  
**Critical rule:** All forward-looking numbers are **NON-EVIDENCE** assumptions until measured. Never present as guaranteed savings.

---

## 1. Purpose

Provide a disciplined way to **design measurement** and track realised operating changes — without converting hope into Board facts.

---

**Good hypotheses (examples of form — not promises)**
- Time-to-code exceptions decreases for pilot slice  
- Unowned exception count decreases  
- Duplicate *candidate* disposition cycle time decreases  
- GR chase response time improves for coded `missing_receipt`  

**Bad hypotheses (do not use)**
- “Save 30% AP cost”  
- “Eliminate fraud”  
- “Achieve compliance”
