# Maturity Assessment — Team Edition

**Product:** Evidence Room — AP Agent OS Team  
**Document ID:** `ER-TEAM-MAT`  
**Version:** 1.0  
**Cadence:** Workshop baseline · Day 90 · Semi-annual  
**Companion:** Free Diagnostic (deeper question bank)

---

## 1. Purpose

Score whether the organisation’s **agent operating layer** is maturing — distinct from whether a particular model is clever.

---

## 2. Dimensions (0–5 each)

| Score | Meaning |
|-------|---------|
| 0 | Absent |
| 1 | Ad hoc |
| 2 | Defined but unused |
| 3 | In use for pilot slice |
| 4 | Managed across AP with evidence |
| 5 | Optimising; assurance-ready discipline |

### D1 — Process clarity
Documented invoice-to-pay; STP definition; handoffs.

### D2 — Exception system
Taxonomy adopted; ownership; ageing by code; huddles.

### D3 — Agent chartering
Job descriptions; exclusions; owners; version control.

### D4 — Responsibility control
L0–L4 registry; promotion packs; demotion practiced.

### D5 — Payment & sensitive controls
Human auth; bank-change verification; SoD with agent prepare.

### D6 — Measurement
Baselines; scorecards; benefits hygiene (no unlabelled claims).

### D7 — Data & evidence logging
Re-performable logs; retention; test environments.

### D8 — Change & skills
Training; pulse; escalation culture; public-AI hygiene.
