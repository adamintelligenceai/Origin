# Evidence Room — AP Agent OS Team Edition

## Implementation — 03 Maturity assessment

**Product:** Evidence Room AP Agent OS — Team Edition  
**Module:** Implementation  
**Standard:** Proof before permission  
**Version:** 1.0  

Maturity is **evidence of operating discipline**, not a score that unlocks L4. Do not use this as a vendor capability model.

---

## 1. What to do

Score the organisation on 12 dimensions, twice a year or at each increment start. Every score needs an artefact pointer. Enthusiasm without a pack ID scores **0**.

**How.** Scale 0–3 below. Independent reviewer (Control or PE not the agent owner) challenges.

**Who.** Transformation facilitates; Head of AP accepts the profile; Control accepts risk-related dimensions.

**Wrong.** Averaging to a single “level 2.7 organisation.” Using maturity to skip Test.

**Control.** Evidence column mandatory. No dimension scored from a workshop vibe.

**Measure.** Dimensions with evidence; change vs last profile.

**Evidence.** `[BUYER]/Evidence/Team/Maturity/[DATE]/`.

---

## 2. Scale

| Score | Meaning |
|---|---|
| **0** | Absent or contradicted (e.g. agent as Accountable) |
| **1** | Written, not operated (template exists, empty folders) |
| **2** | Operated for one slice with evidence |
| **3** | Operated across ≥2 increments/slices with recertification |

Scores are **not** autonomy levels. A company can be maturity 3 at L1.

## 4. How — assessment session (90 min)

1. Owner proposes scores with links (40).  
2. Challenger samples two “3”s — open the folders (30).  
3. Agree profile; list the **one** dimension to raise next (not all) (20).

**Wrong.** Raising D11 by adding a savings slide.
