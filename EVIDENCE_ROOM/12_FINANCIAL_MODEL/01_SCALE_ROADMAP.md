# Scale Roadmap — Digital → Services → Subscription → Platform

**Evidence Room** · AP first · Finance Agent platform later

## Stage 0 — Foundations (now)

| Work | Outcome |
|---|---|
| Free kit + Starter + Custom packs | Sellable ladder |
| Website + landing + email | Capture & convert |
| Claims discipline | Trust |

## Stage 1 — Digital product engine

| Work | Outcome |
|---|---|
| Lemon Squeezy SKUs live | Self-serve cash |
| Pro / Team libraries filled | Higher AOV |
| Marketplace derivatives | Top-of-funnel without cannibalisation |
| Content engine execution | Steady opt-ins |

**Exit criteria:** Repeatable Starter sales; support playbook; NPS/qual feedback themes.

## Stage 2 — Services loop

| Work | Outcome |
|---|---|
| Custom fulfilment QA factory | Margin ≥55% target on Standard band |
| Pattern library from client designs | Feeds Pro updates |
| Optional pilot advisory add-on | Separate SKU — still no savings guarantees |

**Exit criteria:** ≥10 Custom deliveries; three reusable industry patterns (e.g. multi-entity, shared service, high non-PO).

## Stage 3 — Subscription (SaaS)

| Work | Outcome |
|---|---|
| Charter registry | Living operating model |
| Evidence vault | Retention & audit use |
| Stage promotion workflow | Governance cadence |
| Billing | Monthly/annual org licences |

**Packaging sketch:** Seat or org tiers; Starter content included; Pro content gated; Custom remains SOW.

**Exit criteria:** Paying orgs renew; churn drivers understood; security review passed.

## Stage 4 — Finance Agent platform (AP first)

| Domain sequence | Rationale |
|---|---|
| 1. Accounts payable | Volume + controls + KPIs |
| 2. Expense / T&E adjacent | Related intake patterns |
| 3. Order-to-cash select agents | Only after AP evidence discipline holds |
| 4. Close / consolidation assists | Highest governance bar |

## What we will not do early

- Horizontal “AI for all of finance” brand dilution  
- Unattended payment products as lead SKUs  
- Marketplace dumping of core libraries  
- ROI-guarantee pricing  

## Capability investments by stage

| Stage | Invest in |
|---|---|
| 1 | Writing, design system, storefront, analytics |
| 2 | Delivery talent, templates, CRM light |
| 3 | Product engineering, auth, audit log storage |
| 4 | Domain research, partner ERP alignments |

## Narrative for investors / partners

Evidence Room earns the right to platformise by selling governed AP agent design with institutional discipline — then productising the registry and evidence layer buyers already operate by hand.
