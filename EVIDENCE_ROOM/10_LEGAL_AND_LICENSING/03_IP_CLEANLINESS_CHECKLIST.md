# IP Cleanliness Checklist

**Document ID:** `10_LEGAL_AND_LICENSING/03_IP_CLEANLINESS_CHECKLIST`  
**Version:** 1.0  
**Gate:** Must pass before any public release, marketplace listing, or customer ZIP publish.

---

## A. Source hygiene

- [ ] No employer or client confidential process maps, screenshots, or data  
- [ ] No pasted internal Slack/email verbatim  
- [ ] No customer invoice images or vendor names from real estates (unless licensed mock)  
- [ ] No copied proprietary playbooks from Big 4 / vendors  
- [ ] No scraped competitor PDFs rewritten thinly  

## B. Third-party IP

- [ ] Fonts licensed for intended use (web/print/embed)  
- [ ] Icons original or properly licensed  
- [ ] Stock photography rights cleared (prefer none in core product)  
- [ ] Charts using third-party stats cite Research Ledger IDs  

## C. Trademarks

- [ ] ERP/vendor names used nominatively only  
- [ ] No logo misuse of SAP, Microsoft, Oracle, etc.  
- [ ] “Evidence Room” / “Operating Evidence” trademark clearance plan noted  
- [ ] Domain evidenceroom.ai availability flagged for verification  

## D. People & privacy

- [ ] No personal data of real employees in samples  
- [ ] Synthetic examples clearly fictional  

## E. Licence packaging

- [ ] LICENCE.txt included in each ZIP  
- [ ] Copyright year and owner entity correct  
- [ ] Third-party notices file if needed
