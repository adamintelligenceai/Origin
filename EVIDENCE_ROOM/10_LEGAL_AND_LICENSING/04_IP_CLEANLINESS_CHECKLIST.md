# Evidence Room — IP Cleanliness Checklist

**Version:** 1.0 — 20 September 2026  
**Purpose:** Keep AP Agent OS and commercial files free of other people’s proprietary workflows, copy, and data.  
**Use:** Before any zip ships, any article publishes, or any Blueprint file leaves our machine.  
**Flag for lawyer:** trademark search on “Evidence Room” and “AP Agent OS”; copyright in compiled OS; employee/contractor IP assignment.

This is an operating checklist. It is not a legal opinion.

---

## 1. What we own vs what we cite

| Object | Rule |
|---|---|
| Charters, method, packet fields, KPI *definitions*, brand lines | Ours — do not paste from a vendor help centre |
| SAP / Oracle / D365 transaction codes | Do not present as universal. Say “map to yours.” |
| Vendor product names | Nominative, factual. No logos without permission. No “certified for.” |
| APQC / Deloitte / Hackett figures | Cite with source, date, URL, independence. Do not redraw their charts as ours. |
| Lemon Squeezy / Stripe terms | Paraphrase + link. Do not reproduce their legal pages. |
| Buyer data | Never enters the product. ACME is fictional. |
| Prompt-marketplace text | Do not scrape and “improve.” |

---

## 2. Pre-ship checklist (product zip)

- [ ] No client or former-employer SOP pasted in  
- [ ] No screenshot of a vendor UI  
- [ ] No real vendor numbers, IBANs, or invoice images  
- [ ] ACME (or other examples) labelled **fictional / ILLUSTRATIVE**  
- [ ] No invented “customer case study”  
- [ ] Field lists described as objects, not as a named company’s config table  
- [ ] Instruction skeletons labelled **not a magic prompt**  
- [ ] Disclaimer and licence present  
- [ ] No third-party research used as a **target** inside KPI files  
- [ ] No cloned HighRadius / Coupa / Tipalti marketing phrases presented as ours  
- [ ] Filenames do not include a client name  

**Fail:** two or more boxes unchecked. Fix before upload to Lemon Squeezy.

---

## 3. Pre-publish checklist (site, LinkedIn, email)

- [ ] Brand idea and tagline exact  
- [ ] No banned promises  
- [ ] Figures only from `../09_RESEARCH/RESEARCH_LEDGER.md`  
- [ ] Hackett qualifier present if used  
- [ ] No competitor price book  
- [ ] No employee photo used without consent  
- [ ] No stock “neural brain” art  
- [ ] Quotes are ours or attributed  
- [ ] Domain evidenceroom.ai not claimed as trademark-registered until it is  

---

## 4. Blueprint / services extra checks

- [ ] Written permission to observe the buyer’s process  
- [ ] Redaction rules applied before any text enters a model we control  
- [ ] Buyer’s proprietary SOP stays in *their* tenant; we do not reuse it for the next buyer  
- [ ] We do not take their exception codes into the public OS  
- [ ] SOW states we do not acquire their data  

If a Blueprint insight is generic enough to improve the public OS (e.g. a clearer sentence on kill-switch), strip all identifiers and run this checklist again.

---

## 5. Contractor and tool hygiene

| Risk | Rule |
|---|---|
| Freelance writer | Written assignment of IP; no reuse of their other clients’ AP work |
| Design | Fonts are Noto Serif, Inter, JetBrains Mono (licensed/available); no pirated foundry files |
| AI tools | See `05_AI_USE_DISCLOSURE.md`. Do not paste a client SOP into a consumer chatbot. Do not paste our full OS into a public training opt-in. |
| Music / photo | Launch uses none |
| Open source | If we later ship code, a separate licence file. Today we ship documents. |

| Mark | Action |

Do not use a competitor’s product mark in our logo lockup.

---

## 7. Intake from the team (when we have one)

Anyone adding a file answers:

1. Did this come from a named employer or client? If yes, stop.  
2. Did this come from a vendor PDF? If yes, rewrite from first principles or drop.  
3. Is every number labelled ILLUSTRATIVE, TARGET, or sourced in the ledger?  
4. Would Internal Audit think this is *their* confidential process? If yes, stop.

---

## 8. Incident

If we discover a copied workflow in a shipped zip:

1. Pull or replace the LS file the same day.  
2. Mail buyers a corrected zip (v1.0.x).  
3. Write to legal@ with what was copied and from where (if known).  
4. Do not quietly leave the old file up.

---

| Role | Signs |
|---|---|

| Counsel (when retained) | Spot-check before v1.0 public |

v1.0 of the OS may ship with this checklist completed by the author if counsel is not yet retained — the risk is accepted **explicitly**, not forgotten.
