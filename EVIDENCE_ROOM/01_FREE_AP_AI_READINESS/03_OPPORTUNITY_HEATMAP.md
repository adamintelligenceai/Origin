# Opportunity Heatmap

**Evidence Room** · Free tier

Plot where agent work is **valuable**, **feasible**, and **safe** given your diagnostic. Heat is not a savings guarantee.

## Axes

| Axis | Question |
|---|---|
| Value | Does this area consume material AP time or create control risk? |
| Feasibility | Are process, data, and technology bands at least *Capable*? |
| Safety | Do hard gates pass for any path that touches money or master data? |

### Heat key

| Pattern | Heat | Meaning |
|---|---|---|
| Value H + Feasibility H + Safety H | **Pilot now** | Propose-and-confirm agent within bounds |
| Value H + Feasibility M + Safety H | **Prepare** | Fix one feasibility gap, then pilot |
| Value H + Safety L | **Control first** | No agent; remediate gates |
| Value M + Feasibility H + Safety H | **Backlog** | After first pilots |
| Value L | **Defer** | Not worth attention yet |
| Any Safety L on money path | **Blocked** | Hard stop |

## Prioritisation rule

1. Eliminate **Blocked** and **Control first** items from agent pilots.
2. Choose at most **two** *Pilot now* workstreams for 60–90 days.
3. Assign one human owner per pilot and one evidence standard (see Starter operating model).
4. Re-score the heatmap after the pilot — do not expand on anecdotes alone.

## Output for leadership

One paragraph:

> We will pilot **[workstream A]** and **[workstream B]** because value and feasibility are high and control gates pass. We will not automate **[blocked item]** until **[gate]** is remediated. Success means **[KPI]** moves with evidence retained for audit — not a promised cost/invoice outcome.
