# Shadow Mode Method — AP Agent OS Pro

**Evidence Room** · Pro · Testing  
**Definition:** Agent runs in parallel; humans keep the authoritative path; compare outcomes on a sample before promotion

## When to use

After historical test pass; before bounded live pilot at Recommend or higher.

## Principles

1. **No silent authority** — shadow outputs do not post/send unless explicitly designed as dual-run with human still authoritative.  
2. **Same inputs** — agent sees the case state humans saw (as feasible).  
3. **Pre-registered metrics** — agreement, critical misses, evidence completeness.  
4. **Time-boxed** — define end date / volume gate.  

## Setup checklist

- [ ] Charter stage = Observe or Recommend (shadow)  
- [ ] Instruction version pinned  
- [ ] Logging path live  
- [ ] Sample plan written  
- [ ] Buddy coaches assigned  
- [ ] Kill-switch known  
- [ ] Processors trained on “compare, don’t copy blindly”  

## Operating procedure

| Step | Action |
|---|---|
| 1 | Invoice enters in-scope class |
| 2 | Human processes via normal path |
| 3 | Agent produces shadow output to Evidence Room / side panel |
| 4 | On sampled cases, scorer compares human vs agent |
| 5 | Disagreements coded: agent better / human better / both wrong / ambiguous |
| 6 | Weekly scorecard to AP lead |

## Metrics

| Metric | Definition | Gate example (set locally) |
|---|---|---|
| Agreement rate | Shadow = human disposition | ≥ X% |
| Critical miss | Agent would have caused control issue if followed | 0 in sample |
| Evidence completeness | Required fields present | 100% |
| Latency | Time to shadow output | Usable for ops |
| Processor trust pulse | Survey 1–5 | ≥ 3.5 |

## Sample sizes (guidance — not certification)

| Weekly volume in class | Suggested sample / week |
|---|---|
| <50 | All |
| 50–200 | 30–50 |
| >200 | 50 + risk-based extras |

## Exit decision

| Result | Next |
|---|---|
| Gates met | Steering may approve bounded live at ceiling |
| Mixed | Extend shadow; fix instructions; retest |
| Fail | Demote to Observe; remediate |

## Shadow scorecard template

| Week | Volume | Sample n | Agree % | Critical misses | Completeness % | Decision |
|---|---|---|---|---|---|---|

## Anti-patterns

- Treating shadow as free live Recommend without compare  
- Changing instruction version mid-week without noting break  
- Celebrating speed without agreement quality  
- Using Ardent STP **35.4%** as a shadow pass threshold
