## Kill / pause criteria (examples)

- Any S1 (bank/payment path misuse attempt succeeding)  
- Critical miss pattern above threshold  
- Evidence logging failure  
- Owner unavailable without deputy  
- Sponsor withdrawal  

## Retrospective agenda (60 min)

1. What we predicted vs saw  
2. Control performance first  
3. Adoption friction  
4. Instruction defects  
5. Decision: **Expand / Hold / Demote / Stop**  
6. Update risk assessment & charter
