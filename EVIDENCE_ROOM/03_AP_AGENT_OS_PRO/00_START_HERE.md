# AP Agent OS Pro — Start Here

**Evidence Room** · Pro · *Agents that earn responsibility.*  
**Companion rollout layer:** AP Agent OS Team ($499) for workshops, executive packs, and Phases 0–10 facilitation.

Pro is the professional operating library: templates, testing methods, and KPI measurement so a serious AP/Finance team can design governed agents beside Tipalti, Coupa, SAP, Oracle, Bill.com, and peers — without pretending to replace them.

## What Pro is / is not

| Is | Is not |
|---|---|
| Charters, SOPs, RACI, governance, risk, prompts | An AP automation platform or OCR engine |
| Historical test, UAT, shadow, pilot methods | Guaranteed savings, fraud detection, or ROI |
| Weekly report + dashboard specification | Legal, tax, audit, or SOX advice |
| Earn-up operating discipline | “Autonomous AP” |
