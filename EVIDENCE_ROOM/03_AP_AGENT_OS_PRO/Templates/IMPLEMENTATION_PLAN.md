## 1. What to do

Write the allow-list, phases, named owners, gates, caveats, and evidence IDs. Keep timeboxes labelled **ILLUSTRATIVE** until the buyer calendars them.

**How.** Complete §2–§8.

**Who.** Transformation drafts; Head of AP accepts; FinSys accepts Phase 5 dates; Control accepts test gates exist (not the numbers — those are on the charter).

**Wrong.** 4–6 week path used when “well-bounded” tests fail. Payment release in scope.

**Control.** Caveat checklist. Gate IDs.

**Measure.** Tasks without owners; phases without exit packs.

**Evidence.** `[BUYER]/Evidence/Roadmap/[Plan ID]/`.
