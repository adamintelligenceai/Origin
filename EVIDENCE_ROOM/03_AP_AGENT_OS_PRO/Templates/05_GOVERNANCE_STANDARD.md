# Governance Standard — AP Agent OS Pro

**Evidence Room** · Pro · Templates  
**Status:** Operating standard stub — adapt with Internal Audit / counsel  
**Principle:** Agents that earn responsibility.

## 1. Purpose

Define minimum governance for AI agents assisting Accounts Payable so responsibility remains progressive, evidenced, and revocable.

## 2. Applicability

All agents that read, recommend, draft, or (narrowly) execute actions on invoice-to-pay work for entities covered by this standard.

## 3. Definitions

| Term | Definition |
|---|---|
| Charter | Binding description of agent purpose, scope, stage, forbidden actions |
| Stage | Observe / Recommend / Draft / Execute (narrow) / Expand |
| Evidence pack | Retained record of inputs, outputs, decisions |
| Kill-switch | Documented method to disable agent path immediately |

## 4. Mandatory controls

| # | Control | Minimum |
|---|---|---|
| G1 | Charter | Active charter before production |
| G2 | Human owner | Named owner + deputy |
| G3 | Stage ceiling | Documented; Execute requires Controls affirmation |
| G4 | Forbidden actions | Payment release & bank change excluded |
| G5 | Evidence | Per-run minimum fields (see charter) |
| G6 | Sampling | Stage-based sample QA |
| G7 | Change control | Instruction/version pin |
| G8 | Incident & demotion | Severity model + log |
| G9 | Access | Least privilege; recertify quarterly |
| G10 | Claims | No guaranteed savings/fraud/ROI in programme materials |

## 5. Forums

| Forum | Cadence | Authority |
|---|---|---|
| AP huddle | Weekly | Operational |
| Charter Board / Steering | Monthly | Promotions / demotions |
| Controls review | Per prove-in & quarterly | Affirm Execute |

## 6. Promotion ethics

Promote only with pre-registered KPIs and samples.  
Demote without blame when triggers hit.  
Never promote to skip a failing hard gate.

## 7. Relationship to systems of record

This standard governs the **agent layer**. ERP/AP automation platforms remain systems of record under their owners. Evidence Room complements Tipalti, Coupa, SAP, Oracle, Bill.com, and peers — it does not replace them.

## 8. Industry benchmarks

External averages (e.g., Ardent Partners 2025 cost **$9.84**, exception **18.4%**, STP **35.4%**) may appear in training for context. They are not control thresholds unless explicitly adopted as internal targets with measurement plans.

## 9. Exceptions to this standard

Written sponsor + Controls approval; time-boxed; logged in Evidence Room.

| Access | Quarterly |

## 11. Disclaimer

Not legal, audit, tax, or SOX advice. Humans remain accountable. AI can be wrong.
