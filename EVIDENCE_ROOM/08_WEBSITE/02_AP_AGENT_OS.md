## What AP Agent OS is

A structured product family — Free → Starter → Pro → Team → Custom — that equips AP organisations to deploy agents under governance.

## The ten starter agents (A01–A10)

1. A01 Invoice Intake Agent  
2. A02 Invoice Validation Agent  
3. A03 Matching Agent  
4. A04 Exception Triage Agent  
5. A05 Goods Receipt Agent  
6. A06 PO Quality Agent  
7. A07 Approval Agent  
8. A08 Supplier Resolution Agent  
9. A09 Internal Follow-Up Agent  
10. A10 Duplicate / Anomaly Agent  

Pro adds A11–A16 (statements, payment proposal, close, reporting, root cause, orchestrator). Each advances through stages: Observe → Draft → Propose → Bounded execute — only after evidence review. Payment authorization remains human.

## Who it is for

- AP managers in mid-market and enterprise shared services  
- Controllers funding transformation without losing SoD  
- Automation teams tired of unmanaged prompt sprawl  

## Who it is not for

- Teams seeking unattended payment bots on day one  
- Buyers wanting guaranteed cost-takeout  
- Anyone substituting agents for audit opinion
