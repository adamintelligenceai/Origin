What AP Agent OS is

A structured product family — Free → Starter → Pro → Team → Custom — that equips AP organisations to deploy agents under governance. Charters, evidence standards, promotion gates, and demotion hygiene.

The ten starter agents (A01–A10)

  • A01 Invoice Intake Agent
  • A02 Invoice Validation Agent
  • A03 Matching Agent
  • A04 Exception Triage Agent
  • A05 Goods Receipt Agent
  • A06 PO Quality Agent
  • A07 Approval Agent
  • A08 Supplier Resolution Agent
  • A09 Internal Follow-Up Agent
  • A10 Duplicate / Anomaly Agent

Pro adds A11–A16 (statements, payment proposal, close, reporting, root cause, orchestrator). Each advances Observe → Draft → Propose → Bounded execute — only after evidence review. Payment authorisation remains human.

Who it is for

  • AP managers in mid-market and enterprise shared services
  • Controllers funding transformation without losing SoD
  • Automation teams tired of unmanaged prompt sprawl

Who it is not for

  • Teams seeking unattended payment bots on day one
  • Buyers wanting guaranteed cost-takeout
  • Anyone substituting agents for an audit opinion
