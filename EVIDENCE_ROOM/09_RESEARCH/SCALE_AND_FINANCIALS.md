# Path

1. **AP digital products** (this repo) — prove willingness to pay  
2. **Productised Blueprint** — learn implementation language from real intakes  
3. **Selective implementation assists** — still not a software company  
4. **Recurring subscription** (later): update cycle for taxonomy, controls, KPI dictionary, office hours  
5. **Evidence Room Finance Agent Platform** (SaaS, later): registries, scorecards, evidence packs as software  
6. **Horizontal modules** (not now): AR, Close, Treasury, Reconciliations, Controls, FP&A

# Cost

Near-zero marginal delivery (zip + email). Real costs: time, ads if any, counsel, accounting, LS fees, refunds. Do not hire delivery staff until Blueprint backlog is real.

# Pricing integrity

Do not race prompt-pack pricing. $199 is the reference SKU. If conversion is weak, improve the preview and diagnostic, not a $29 Professional.
