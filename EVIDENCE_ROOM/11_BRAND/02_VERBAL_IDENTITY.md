# Verbal Identity — Evidence Room

**Master line:** Agents that earn responsibility.  
**Register:** Executive, finance-native, specific, calm.  
**Reader assumption:** Competent AP/Finance professional; short on time; allergic to hype.

---

## 1. Voice attributes

| Attribute | In practice |
|---|---|
| **Precise** | Prefer “exception rate” and “promotion gate” over “supercharge your AP” |
| **Accountable** | Always name the human owner when discussing agent action |
| **Complementary** | “Beside Coupa/Tipalti/SAP,” never “rip them out” |
| **Evidence-bound** | Numbers only from the research ledger or labeled illustrative |
| **Progressive** | Speak in earn-up stages, not binary “AI on/off” |

**Person:** Second person for instructions (“Assign a human owner”); first person plural sparingly for the company (“We label illustrative models”). Avoid first-person agent anthropomorphism (“I will pay your invoices”).

**Tense:** Present for product behavior; past only for sourced report findings.

---

## 2. Banned phrases (do not use in customer-facing copy)

### Hype / cliché
- Revolutionize, disrupt, supercharge, magical, seamless (as a blanket claim), next-gen, cutting-edge, game-changer, unlock the power, harness AI, AI-powered (as empty adjective stack)
- Autonomous AP, set and forget, replace your AP team, zero-touch everything
- Robot / bot army / digital workers (as mascot language)
- Neon / “futuristic finance” aesthetic language

### Unsourced or overclaim
- Any savings %, fraud reduction %, compliance guarantee, or ROI multiple without ledger + labels  
- “Best-in-Class results” as product promise (Ardent BiC is **their** cohort, not ours)  
- Inflated TAM from Grand View Research without methodology caveat — prefer omit  

### Soft evasion
- “Guaranteed,” “ensure compliance,” “eliminate fraud,” “audit-proof” (nothing is)  
- “The AI decides” without human owner  

### Competitor mud
- “Tipalti killer,” “Coupa alternative” as primary frame  
- Fake rankings (“#1 AP AI”)

## 4. Sample headlines (approved patterns)

### Brand / home
- Agents that earn responsibility.
- Evidence before autonomy.
- The governed agent layer for Accounts Payable.

### Problem
- Your AP stack processes invoices. It does not govern agents.
- Average cost per invoice is still measured in dollars, not pennies — see Ardent. Your baseline still matters more.
- STP remains a minority outcome in published averages. Autonomy without gates will not fix that quietly.

### Product
- AP Agent OS Pro — operating model, controls, and KPIs in one pack.
- Start in Observe. Promote only with evidence.
- Built to sit beside Tipalti, Coupa, SAP, and the rest — not to pretend it is them.

### Trust
- No guaranteed savings. No guaranteed fraud detection. Clear human accountability.
- Show Audit the promotion log — not a chat screenshot.

### Commercial
- Free readiness scorecard. Starter for one pilot. Pro for the OS. Team when shared services need one method.

## 6. Product naming taxonomy

### Suite
- **Evidence Room** — brand / company product house  
- **Evidence Room AP Agent OS** — commercial suite name  

### SKUs (external names)

| Code | External name | Short |
|---|---|---|
| 01 | **AP AI Readiness Scorecard** (Free) | Readiness |
| 02 | **AP Agent Starter** | Starter |
| 03 | **AP Agent OS Pro** | Pro |
| 04 | **AP Agent OS Team** | Team |
| 05 | **AP Agent Custom Blueprint** | Custom Blueprint |

### Internal artifact types (within Pro/Team)

| Type | Naming pattern | Example |
|---|---|---|
| Agent role card | `Agent — {Function}` | Agent — Exception Triage |
| Control | `Control — {Name}` | Control — Dual Control Payments |
| KPI | `KPI — {Metric}` | KPI — Exception Rate |
| Template | `Template — {Use}` | Template — Steering Committee Brief |
| Gate | `Gate — {Stage}` | Gate — Recommend to Draft |
| Evidence object | `Evidence — {Object}` | Evidence — Promotion Record |

### Earn-up stages (canonical spelling)
1. Observe  
2. Recommend  
3. Draft  
4. Execute (narrow)  
5. Expand  

Do not rename stages per SKU.

### Versioning
`{SKU} v{MAJOR}.{MINOR}` — e.g., `AP Agent OS Pro v1.0`  
Changelog cites research ledger refresh when numbers change.
