# Brand System — Evidence Room

**Product suite:** Evidence Room AP Agent OS  
**Institutional references (feel, not imitation):** Bloomberg Terminal clarity, Stripe documentation restraint, McKinsey deck discipline, public-company annual report typography  
**Anti-references:** Neon AI startups, robot mascots, purple gradients, “autonomous finance” hype posters

---

## 1. Brand platform evaluation (5 options)

Evaluate each on: CFO/Controller dignity, differentiation, earn-up fit, longevity, anti-hype.

### Platform A — “Control the agents before they control the close.”
- **Pros:** Urgent; audit-aware.  
- **Cons:** Fear-led; adversarial toward AI; ages into scare marketing.  
- **Score:** 6.5/10 — usable for Risk one-pagers, not master brand.

### Platform B — “AP automation’s missing operating system.”
- **Pros:** Category-clear; stack-complementary.  
- **Cons:** “OS” alone is techy; understates human accountability; could be confused with software runtime.  
- **Score:** 7.5/10 — strong subtitle / category line.

### Platform C — “Evidence before autonomy.”
- **Pros:** Precise; audit-native; pairs with product name.  
- **Cons:** Slightly abstract for AP managers; less verb energy.  
- **Score:** 8/10 — excellent supporting line.

### Platform D — “Finance-grade AI for invoice-to-pay.”
- **Pros:** Domain clear.  
- **Cons:** Crowded claim space; sounds like another AP AI feature vendor; weak on governance.  
- **Score:** 5/10 — reject as master platform.

### Platform E — “Agents that earn responsibility.”
- **Pros:** States the product principle; progressive trust; human-respecting; unique vs Tipalti/Coupa/HighRadius autonomy stories and vs prompt marketplaces; works in headlines, covers, and methodology.  
- **Cons:** Requires one explanatory beat for new audiences (solved by supporting lines).  
- **Score:** **9.5/10 — SELECTED.**

## 2. Selected platform

### Master line
# Agents that earn responsibility.

### What it means (internal)
Responsibility is not granted by buying a model. It is **earned** through evidence, KPI gates, controls, and human ownership — and it can be revoked.

### Supporting lines (approved)
1. **Observe → Recommend → Draft → Execute (narrow) → Expand.**  
2. **Evidence before autonomy.**  
3. **The governed agent layer for Accounts Payable — beside your stack, not instead of it.**  
4. **Built for Controllers who will not rubber-stamp AI.**  
5. **Promotion gates for agents. Accountability for humans.**  

### Category cue (when needed)
**AP Agent Operating System** — governance and operating model for an agent workforce.

### Boilerplate (50 words)
Evidence Room is an AP Agent Operating System: templates, controls, KPIs, and earn-up playbooks so finance teams can put AI to work on invoice-to-pay without pretending agents are already trustworthy. It complements your AP and ERP stack. Agents that earn responsibility.

## 4. Visual system

### 4.1 Color

| Token | Hex | Role |
|---|---|---|
| **Deep ink** | `#0B1F2A` | Primary text, covers, nav, authority surfaces |
| **Paper** | `#F7F4EE` | Page background, print feel |
| **Signal amber** | `#C47A2C` | Emphasis, CTAs, “earn-up” markers, warnings that need action (not alarmist red by default) |
| **Trust teal** | `#1F5C5C` | Secondary accent, links, success/verified states, diagram secondary |
| **Rule grey** | `#8A8580` | Rules, captions, tables, hairlines |
| **Ink muted** | `#3D4F5A` | Body secondary |
| **Paper elevated** | `#FFFCF7` | Cards only when interaction requires (prefer no cards) |
| **Hairline** | `#D9D2C7` | Dividers on paper |
| **Danger (rare)** | `#8B2E2E` | True control failure / demote — sparingly |

**Rules**
- No purple, no neon, no multicolor gradients as brand identity.  
- Backgrounds: paper with subtle grain or soft ink→paper vertical wash — not flat pure white app chrome as the brand hero.  
- Amber is **signal**, not decoration candy.

### 4.2 Typography

| Role | Font | Notes |
|---|---|---|
| **Display / covers / H1** | **Fraunces** (preferred) or **Source Serif 4** | Literary-institutional; optical sizing if available |
| **UI / body / tables** | **IBM Plex Sans** | Credible, finance-adjacent; excellent figures |
| **Mono / evidence IDs / prompts** | **IBM Plex Mono** | Agent IDs, ledger keys, CLI-ish evidence |

**Explicitly banned as brand defaults:** Inter, Roboto, Arial, system-ui-only stacks for marketing surfaces.

**Type manners**
- Display: tighter tracking on large covers; avoid faux-bold.  
- Body: 1.5 line-height; comfortable measure (~65–75 characters).  
- Tables: Plex Sans; right-align numbers; tabular lining figures where possible.

### 4.3 Logo / wordmark direction

- **Wordmark:** “Evidence Room” in Fraunces or a custom serif cut; weight Medium/Semibold; optical balance.  
- **Descriptor lockup:** `AP AGENT OS` in IBM Plex Sans, tracked small caps or spaced uppercase, teal or rule grey — never competing with the wordmark size.  
- **Mark (optional):** Abstract **open docket / evidence tab** — a vertical tab with a single amber rule — *not* a robot, eye, shield-with-lightning, or neural net node graph.  
- **Clear space:** Cap-height of the “E” on all sides.  
- **Minimum:** Wordmark only below ~120px width; drop descriptor.

### 4.4 Cover system (PDF / PPT / pack)

**Composition (first viewport / cover)**
1. Deep ink full-bleed field **or** paper field with ink header bar.  
2. Wordmark (brand-first — larger than headline).  
3. One headline (platform or product name).  
4. One supporting sentence.  
5. One amber rule (1–2px) as institutional accent.  
6. Footer: SKU · version · “Agents that earn responsibility.”

**No:** floating badges, robot art, stock “handshake AI,” purple glow, card grids on covers, emoji.

**Motion (site / product later):** 2–3 intentional motions only — e.g., amber rule draw-on, ink fade of earn-up stages, restrained page fade. No particle fields.

### 4.5 Imagery
- Real AP/finance context: desks, ledgers, anonymized dashboard crops, meeting rooms — desaturated, documentary.  
- Diagrams: ink + teal + amber rules; flat institutional, not isometric SaaS toys.

### 4.6 UI chrome (when digital products appear)
- Paper backgrounds; ink text; teal links; amber primary button.  
- Prefer lists and tables over card walls.  
- Radius: 2–4px max — not pill-heavy.

## 6. Brand test (mandatory)

1. **Remove the nav.** Does the first viewport still say Evidence Room? If not, branding is too weak.  
2. **Would this slide survive a Controller’s forwarding to Audit?** If embarrassed, revise.  
3. **Could a generic AI startup reuse this with a find-replace?** If yes, sharpen earn-up language and institutional visuals.
