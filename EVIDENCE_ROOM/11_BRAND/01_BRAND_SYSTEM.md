**Selected brand idea:** AI that earns responsibility.

**Master line:** The operating system for building, governing and scaling AI agents across Accounts Payable.

**Supporting lines (max three):**

1. Evidence over hype.  
2. Governed agents. Measurable outcomes.  
3. It does not replace the AP stack. It designs the agent layer that operates across it.

## 2. Brand idea, expanded

Evidence Room treats an AP agent like a new analyst: hired against a job description, observed, measured, and given more responsibility only when the evidence supports it.

The “room” is not a data room. It is the place where work, controls, and proof live together — the operating room for a Finance agent workforce.

## 3. Voice

| We sound like | We do not sound like |
|---|---|
| A precise Finance Director | A launch-week AI startup |
| An internal audit memo that someone actually wants to read | A prompt marketplace |
| Institutional research | A thought-leadership newsletter |
| Specific (“price variance outside 2% / USD 25”) | Vague (“unlock the power of AI”) |

**Rules**

- Prefer nouns and verbs over adjectives.  
- One idea per sentence.  
- Name the object: invoice, GR, DoA, legal entity.  
- Never use “revolutionise,” “seamless,” “next-gen,” “magic,” “set and forget.”  
- Never promise a number you cannot source.  
- Humour, if any, is dry and rare.

**Words we use:** agent, charter, owner, guardrail, exception, evidence, shadow mode, promotion gate, residual risk, straight-through, responsibility level.

**Words we refuse:** autonomous AP (as a default), touchless (as a promise), AI-powered (naked), intelligent automation (empty), digital workforce (without governance), fraud-proof, guaranteed ROI, compliant-by-design.

## 4. Category language

- **Category we claim:** Finance Agent Operating System.  
- **First module:** AP Agent OS.  
- **Category we refuse:** AP software, invoice OCR, payments, prompt pack, ebook.

Comparison lines:

| Versus | Line |
|---|---|
| Prompt packs | A prompt is an instruction. An operating system is a job, a control, a measure and a promotion rule. |
| AP software | Those products process invoices. This product designs the agent layer that works across them. |
| Big Four toolkits | Those arrive with a team and a statement of work. This arrives on Friday and is usable on Monday. |
| “Autonomous finance” vendors | They sell execution. We sell earned responsibility. Payment authority stays human. |

## 5. Visual system

**Mark:** a square room — 1.5pt ink stroke — with a single oxblood vertical bar inset from the left (the evidence spine). No eye, lock, robot, spark, or neural net.

**Wordmark:** `EVIDENCE ROOM` in Tinos, tracking +80, small caps.  
**Product line:** `AP AGENT OS` in JetBrains Mono, 10–11pt, slate.

**Colour**

| Token | Hex | Role |
|---|---|---|
| Ink | `#14110E` | Text, rules |
| Paper | `#F6F1E8` | Ground |
| Vellum | `#EFE8DC` | Panels |
| Rule | `#C8BDAA` | Hairlines |
| Oxblood | `#7A1F2B` | Mark, CTA, critical |
| Forest | `#1F4A3A` | In control |
| Bronze | `#8A6A32` | Observe / caution |
| Slate | `#5C5852` | Secondary |
| White | `#FFFcf6` | Contrast |

**Type:** Inter (body/UI) · Tinos (display) · JetBrains Mono (IDs, formulas).

**Cover:** paper ground, 8pt oxblood bar at left, wordmark top-left, family name top-right, serif title, one-line promise, document code + version at the foot. No photography.

**Charts:** ink strokes, vellum fills, oxblood for the series that matters, forest for in-control, bronze for baseline. Direct labels. No legends if one series. No 3D. No rainbow.

**Tables:** header in ink on vellum, hairline rows, numeric right-aligned, codes in mono.

**Callouts**

- *Do* — forest left rule.  
- *Do not* — oxblood left rule.  
- *Evidence* — bronze left rule with ledger ID.
