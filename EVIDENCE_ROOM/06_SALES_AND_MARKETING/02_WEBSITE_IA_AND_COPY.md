# Assess Your AP Agent Readiness.

[ Start the diagnostic ]  ← name, work email, role, organisation, country

## What we ask (preview — keep it short)

Answer 18 items. About twelve minutes. Honest beats flattering.

**Owners.** Is there a named human Accountable for invoice intake, matching, exceptions, and payments — not a mailbox?  
**Slice.** Can you name one legal entity and one channel you would shadow first?  
**Human classes.** Is payment release forbidden to automation in writing? Bank-change dual control? Policy exceptions? Legal mail?  
**Evidence.** Do you retain source files and document IDs today, or only the posted invoice?  
**Measurement.** Do you have a frozen baseline for first-pass yield and cycle time on that slice?  
**Fallback.** If the model vendor is down tomorrow, does AP still run in the ERP?  
**Identity.** Would an agent use a shared human login, or a named identity with an allow-list?  
**Change.** Can you pin a model ID and treat a swap as a release?

Each item: Yes / Partial / No / Not sure.

## What you receive

- A readiness score in four bands: Owners, Evidence, Measurement, Permission.  
- A recommended first slice (entity × channel × three to five agents) — advisory, not a mandate.  
- The gaps that would make an L2 draft irresponsible.  
- A one-page brief you can forward to the Controller.  
- A 14-day sequence that explains the OS without spam.

# METHOD `/method`

**Title:** The Evidence Room Method  
**Purpose:** Trust. Teach the ten steps. Convert to Diagnostic.

**Overline:** METHOD

# Observe first. Expand responsibility last.

The method converts a live Accounts Payable operation into a governed agent workflow. Do not skip steps to “get to the agent faster.” Permission is earned by evidence produced in earlier steps.

```
Observe → Transcribe → Extract → Structure → Agentise
    → Test → Shadow → Controlled Pilot → Measure → Expand responsibility
```

If Measure fails, return to Test or Agentise. Do not jump to Expand.

## The ten steps (public)

**1. Observe.** Record how invoices, exceptions, approvals, and payments actually move — not how the SOP says they move.

**2. Transcribe.** Turn observation and recordings (where policy allows) into a structured transcript. Redact what must not enter a model.

**3. Extract.** Pull objects, events, controls, and exceptions from the transcript.

**4. Structure.** Write the SOP and RACI so a stranger could run the desk.

**5. Agentise.** Map work to charters. Default L0. Name forbidden tools.

**6. Test.** Labelled historical pack. Buyer-owned. Vendor demo sets do not count.

**7. Shadow.** L0. The agent writes what it would have done. Operators do not work from it.

**8. Controlled pilot.** L1 or L2 on a published slice. Park, do not silently post.

**9. Measure.** Four KPI families. Risk-control can veto.

**10. Expand responsibility.** One increment. One slice. New evidence pack.

Timeboxes are planning ranges you set. We do not publish a guaranteed calendar.

[ Assess Your AP Agent Readiness ]

## Operating rule for every step

What to do. How. Who. What can go wrong. Control. Measure. Evidence.

That seven-line habit is the house. It is how a page in this product is written, and how a Monday meeting should run.
