# Evidence Room — Marketplace Derivatives

**Purpose:** Small, Etsy-style and marketplace-style acquisition products that introduce the house without cannibalising Starter, Professional, or Team.  
**Rule:** If a $19 file contains the promotion method, the 16 charters, or the KPI dictionary, it *is* the core bundle. Do not sell that on Etsy.  
**Brand:** Same voice, paper covers, no robots. Each derivative points to evidenceroom.ai/diagnostic.  
**Date:** 20 September 2026

---

## 1. What “does not cannibalise” means

A derivative is safe if a buyer can own it **and still need Professional** to implement an agent programme.

| Safe | Unsafe (do not list) |
|---|---|
| One-page posters, checklists, worksheets | The 16 charters |
| A 6-page explainer of L0–L4 without gates-as-config | Autonomy progression in full |
| A redacted packet *example* (fictional) | Packet standard + all failure modes |
| A 10-term glossary | KPI dictionary and scorecard |
| A diagnostic preview (3 of 18 items) | The scored diagnostic engine itself, sold twice |
| Printable RACI *blank* with four roles | Completed RACI + SOP generator |

If a reviewer can run Monday from the derivative alone, pull it.

Derivatives are working if they produce **diagnostic completes**, not if they maximise Etsy revenue. If Professional sales fall while $19 glossary sales rise, tighten D4 and D9 and remove D6 if it is substituting for Starter.

Proof before permission.
