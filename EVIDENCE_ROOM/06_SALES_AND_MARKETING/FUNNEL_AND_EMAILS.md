**Email 2 — Misconception**  
Subject: AP automation is not an agent operating model  
Most teams buy capture and still live in exceptions. Ardent’s 2025 work puts average exceptions at 18.4% and STP at 35.4%. An agent layer that is not chartered becomes another unofficial spreadsheet. Tomorrow: pick the first exception code you would give a junior analyst. That is your first agent candidate.

**Email 3 — First agent**  
Subject: How to identify the first AP agent  
Use four filters: volume, pain, data, reversibility. Goods receipt chase and exception triage usually beat payment review. Write exclusions before prompts.

**Email 4 — Responsibility**  
Subject: Agents earn responsibility  
Level 0 observe. Level 1 recommend. Level 2 prepare. Level 3 execute a written list. Level 4 is rare. Payment authorisation is not a level. It is a human role.
