# Evidence Room — AP Agent OS

The operating system for building, governing and scaling AI agents across Accounts Payable.

**Responsibility is earned.**

This repository is the commercial product suite: research, brand, diagnostic, Starter ($79), Professional ($199), Team ($499), Custom Blueprint, Lemon Squeezy operations, website copy, 90-day content system, and legal drafts.

## Start

1. Read `EVIDENCE_ROOM/00_READ_ME/00_REFINED_MASTER_PROMPT.md` — the tightened execution spec.
2. Open `EVIDENCE_ROOM/00_READ_ME/README.md` — navigation for buyers and operators.
3. Work the numbered folders `01` → `10`.

## What this is not

A prompt pack, an ERP, an accounting system, or an autonomous payment product. Humans authorise payments. Statistics are cited in `EVIDENCE_ROOM/09_RESEARCH/RESEARCH_LEDGER.md`.
